## 1. 表设计（迁移 `_118`，九新表，全带 project_id 归属）

### T1 闭环内聚件（五表）

**`qms_ncr_capas`（B3-04 NCR/CAPA）**：id / project_id / code（项目内唯一）/ title / source_alert_id（从预警转入）/ stage CHECK(draft,analysis,action,verification,closed,rejected) / recurrence_count Integer default 0 / verification_cycles Integer default 0（连续无复发周期数，三周期达标方可关）/ reject_reason / created_by_id / closed_at / created_at / updated_at + 子表 `qms_ncr_actions`（ncr_id/phase/action/note/actor_id/created_at——轨迹）。

**`qms_d8_reports`（B3-03 8D）**：id / project_id / code / case_id nullable / ncr_id nullable / current_step Integer default 0（D0–D8）/ steps JSON（每步内容+确认人+确认时间）/ d6_passed Boolean default false / closed_at / created_by_id / created_at / updated_at。

**`qms_cases`（B3-07 案例中心）**：id / project_id / code / title / severity CHECK(low,medium,high,critical) / status CHECK(open,monitoring,closed) / source_alert_id nullable / keywords / created_by_id / closed_at / created_at / updated_at + `qms_case_links`（case_id/object_type/object_id——关联处置/NCR/8D/知识/报告/模型卡/控制计划版本）。

**`qms_knowledge_entries`（B3-10 知识库）**：id / project_id / defect_code / symptom Text / root_cause Text / action Text / effectiveness Text / device_ref / created_by_id / created_at / updated_at（向量检索走 RAG 基建挂接，本批先关键词检索+向量挂点登记）。

**`qms_trace_links`（B3-09 批次追溯）**：id / project_id / sample_key / batch_no / alert_id nullable / ncr_id nullable / inference_result_id nullable / dataset_version_id nullable（四对象串联查询的实现层——由样本键查询时聚合，本表登记显式链接）。

### T2 报告与控制（两表）

**`qms_quality_reports`（B3-08）**：id / project_id / period CHECK(daily,weekly,monthly) / period_key String(16)（如 20261126）/ params JSON / content JSON（NG 率/Cpk 达标率/预警总量/Top 缺陷与设备/NCR 概况——从 quality_aggregates 同源）/ html Text / generated_by CHECK(scheduler,manual) / created_by_id / created_at；UNIQUE(project_id, period, period_key, generated_by)。

**`qms_control_plans`（B3-06）**：id / project_id / code / version Integer / status CHECK(active,archived) / quality_points JSON（质量点+基础抽样量）/ tightening_multiplier Float default 1.0 / decision_log JSON（四因子窗口/取数/权重/理由）/ effective_from / archived_at / created_by_id / created_at。**双生效拒绝**：项目内 active 唯一（服务层强制；迁移级部分唯一索引 SQLite 不支持，落服务层强校验）。

### T3 工具件（三表）

**`qms_msa_studies`（B3-01 MSA）**：id / project_id / name / part_count / operator_count / replicates / data JSON（读数矩阵）/ grr_percent Float nullable / ndc Integer nullable / grade CHECK(acceptable,conditional,unacceptable) nullable / created_by_id / created_at。

**`qms_fmeas`（B3-02 FMEA）**：id / project_id / name / items JSON（失效模式行：失效模式/影响/S/O/D/预防措施；RPN 服务端算）/ created_by_id / created_at / updated_at + `qms_fmea_sync_log`? 不单设——同步动作进控制计划决策流水与审计。

**`qms_iqc_scar`（B3-05 IQC→SCAR）**：id / project_id / supplier_name / supplier_code / status CHECK(active,disabled) / —— 拆两表：`qms_suppliers`（供应商台账：id/project_id/code/name/status）与 `qms_iqc_records`（来料检验：id/project_id/supplier_id FK/arrival_count/inspected_count/defect_count/constraint_ok Boolean/scar_id nullable/created_by_id/created_at）+ `qms_scars`（id/project_id/iqc_record_id 唯一 FK/cause/correction/verification/closed_at/status）。

## 2. 服务层（services/qms/ 四文件）

- `services/qms/ncr.py`：`create_ncr`（手工或 alert_id 转入——自动带证据链引用）/ `transition_ncr`（顺序推进守卫）/ `reject_ncr`（draft/analysis + 理由必填）/ `close_ncr`（**三周期无复发门禁**：verification_cycles ≥3 且周期内无同场景+同工位新预警/判异；未达 → NCR_CLOSE_BLOCKED）/ `evaluate_recurrence`（接 quality_alerts + SPC 判异查询）。
- `services/qms/d8.py`：`create_d8` / `advance_step`（current_step+1 顺序守卫，跳步 D8_STEP_ORDER_ENFORCED）/ `close_d8`（**d6_passed=false → D6_GATE_NOT_PASSED**）/ `draft_with_llm`（D1–D5 初稿经网关——自动入 B2-08 动作审计）/ `detect_recurrence`（同类新 NCR → 提示重开）/ `export_evidence`（zip 先例）。
- `services/qms/cases.py`：`open_case_from_alert`（critical 关闭钩子，F2 处置流后挂）/ `search_cases`（项目/状态/关键词/严重度/时间）/ `link_object` / `repush_status`（NCR 关闭→案例关闭候选规则单测）。
- `services/qms/reports.py`：`generate_report(db, project_id, period, period_key, generated_by)`——NG 率/Cpk 达标率从 `quality_aggregates`（F3 单一聚合口径模块）取数；beat `qms-report-scheduler`（600s）；HTML/JSON 导出。
- `services/qms/control_plan.py`：`create_or_replace_plan`（新版生效+旧版归档+双生效拒绝）/ `evaluate_tightening`（四因子取数：B1-09 漂移/B1-01 预警/B1-06 Cpk/B3-04 复发 → 建议乘数 → **进 S1 审批队列（recipe_change 类型）**）/ `version_diff`（相邻版本质量点/抽样量/乘数逐项对比）。
- `services/qms/msa.py`：`compute_grr`（均值极差法 %GRR/ndc/分级——纯函数+手算向量单测）。
- `services/qms/fmea.py`：items 服务端 clamp+RPN 计算（前端只读）/ `sync_to_control_plan`（生成待审批变更）。
- `services/qms/iqc.py`：`record_iqc`（数量约束校验：inspected≤arrival、defects≤inspected → 违反 IQC_COUNT_CONSTRAINT）/ `on_iqc_fail`（自动生成唯一 SCAR：一检验一 SCAR，重触发复用）/ `disable_supplier`（停用后新来料被拒 SUPPLIER_DISABLED）。
- `services/qms/knowledge.py`：关键词/缺陷代码/设备筛选 + `search_by_symptom`（Top5 相似：本批关键词相关度实现 + 向量检索挂点登记）。
