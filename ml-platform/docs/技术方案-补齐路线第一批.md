### 4.2 SQL 白名单（sqlglot）

- 校验矩阵（单测锁死，含绕过用例）：单语句；根节点 SELECT（WITH→SELECT）；拒绝 INTO OUTFILE / COPY TO / DML / DDL；危险函数清单拒绝（pg_sleep/sleep/benchmark/load_file 等）；无 LIMIT 自动补；注释由解析器剥除
- 绕过用例覆盖：多语句、注释绕过、引号内分号、嵌套子查询带 `;DROP`、UNION 构造越权读（同库范围内允许 UNION，只受白名单结构约束）
- 引擎管理：任务内引擎缓存（pool_pre_ping + 小连接池），celery fork 安全（先例 `services/knowledge_graph_llm_extraction.py:341-352`）；连接超时 5s
- 界面与文档明示：只读 = 白名单 + 只读账号双防线，白名单拦 DML 但不能防「账号本身越权读」，账号治理归现场

### 4.3 导入为数据集

- 执行白名单 SQL → 流式导出临时 CSV（cap 100 万行，沿用数据集导入上限）→ 复用既有数据集导入状态机（parse→confirm，`services/data_import.py`）——外部数据源侧只负责取数存临时文件，导入逻辑零重复
- sample_id_column 等导入选项在导入确认步继续可用（`data_import.py:346-356`/`495-559`）

### 4.4 主密钥轮换工具（E17）
