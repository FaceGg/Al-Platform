# 标注员门户重设计方案

日期：2026-09-18
状态：待评审
关联：`2026-09-01-general-automl-annotation-platform.md` §8（标注员门户、指派和回传）

## 1. 背景与目标

标注员门户（8443）现有功能可用但体验停留在"管理后台"层面：队列是一张筛选表格，工作区逐条翻页，无键盘流、无反馈闭环、无个人视角。本方案借鉴 Label Studio、CVAT、Labelbox、Scale、Prodigy、Toloka、Appen 等平台的标注员端实践，将门户重构为**以标注员为中心的连续作业界面**。

目标：
1. 提升标注效率：键盘流 + 连续标注，减少鼠标往返。
2. 闭合反馈回路：驳回/批注先于新任务被看见，重做有上限与申诉。
3. 建立个人视角：进度、质量、待办一目了然。

## 2. 现状盘点（摘）

- 页面：登录/注册 + "我的任务"队列（搜索/状态筛选/排序/分页）+ 工作区（样本分页、草稿自动保存、冲突提示、评论线程、批量标注、样本搜索、完成确认、退回重编辑）+ 通知。
- 门户后端（FastAPI）将数据面请求代理到主平台 `/api/internal/portal/*`，认证走 `portal_session` cookie。
- 缺失：键盘快捷键、连续标注流、跳过/存疑、指南常驻、驳回置顶、个人仪表盘、新手引导、领取加锁提示。

## 3. 业界经验要点（指导取舍）

| 经验 | 来源 | 采纳 |
| --- | --- | --- |
| 队列页 → 连续标注流，提交即下一题 | Label Studio、Prodigy | P0 |
| 选项类控件必须绑数字快捷键 | Toloka、Prodigy | P0 |
| 回车提交、空格跳过、Ctrl+Z 撤销、F1 帮助 | Prodigy、CVAT | P0 |
| 驳回反馈置顶队列首页，先看反馈再领新任务 | Appen | P0 |
| 指南常驻侧栏 + 好坏示例 | AWS GT、Toloka | P0 |
| 跳过样本回队尾带标记，不静默丢弃 | Scale | P1 |
| 最近 N 条撤销历史侧栏 | Prodigy | P1 |
| 个人仪表盘（吞吐/驳回率/趋势） | Labelbox | P1 |
| rework 上限 2 次 + 申诉入口 | Appen | P2 |
| 入门 quiz / 校准批门控 | Labelbox、Scale | P2（暂缓，依赖任务侧配置） |
| 一屏一样本、字段分组、选项>5 评估拆分 | Toloka、doccano | 设计约束 |

反面模式规避：双开标签页重复领题（领取加锁已有服务端指派语义，前端补提示）；无解释驳回（批注线程已具备，需置顶呈现）。

## 4. 信息架构

```
门户
├── 登录 / 注册（现有）
├── 仪表盘「今天」            ← 新增（P1）
│   ├── 待处理反馈（驳回/批注）置顶
│   ├── 进行中任务卡（进度条、截止倒计时）
│   └── 个人指标（今日完成、本周完成、驳回率）
├── 任务队列（现有页重构）    ← P0
│   ├── 反馈横幅：有未读驳回时置顶，进入即引导处理
│   └── 任务卡：任务名、状态、我的进度 x/y、截止时间、[继续标注]
└── 工作台（现有页重构）      ← P0 核心
    ├── 顶栏：任务名 · 进度 · 保存状态 · 退出
    ├── 左栏（常驻）：任务说明 + 标签说明（好坏示例）
    ├── 中央：一样本一屏，字段分组高亮当前标签列
    ├── 右栏：标签控件（单/多选，绑定数字键）、跳过/存疑
    └── 底栏：← 上一条 | 进度 n/N | 下一条 →（提交后自动前进）
```

## 5. 核心交互规范

### 5.1 连续标注流（P0）
- 工作台改为"样本流"模式：保存/提交当前样本后 600ms 内自动载入下一样本；队尾显示完成汇总。
- 保留"翻页浏览"作为次级模式（表格视图折叠在"浏览全部"入口后），满足回查场景。

### 5.2 键盘快捷键（P0）
| 键 | 行为 |
| --- | --- |
| 1-9 | 勾选/取消对应标签选项（按显示顺序） |
| Enter | 保存并进入下一样本 |
| Space | 跳过当前样本（标记 skipped，P0 先本地跳过，P1 回队尾） |
| ←/→ | 上一个/下一个样本（不保存） |
| Ctrl+Z | 撤销最近一次标签修改（前端撤销栈，最近 20 步） |
| F1 / ? | 快捷键帮助浮层 |

### 5.3 反馈闭环（P0 置顶 + P1 重做上限）
- 队列页与工作台顶部：存在未读驳回批注时显示横幅，点击直达对应任务的评论线程。
- 退回重编辑的指派在队列中标记「需重做」并排前；同一指派重做次数 ≥2 时提示可申诉（P2 接入申诉表单，暂为批注留言）。

### 5.4 保存与冲突（沿用现有契约）
- 自动保存（防抖 2s）+ 修订号乐观锁不变；冲突时保留两侧值并高亮差异，不强覆盖。

### 5.5 视觉
- 沿用 antd，门户独立浅色主题；任务卡/进度条复用主平台视觉语言；移动端不做适配（表格标注场景）。

## 6. 后端增量（尽量复用现有 /api/internal/portal/*）

| 能力 | 方案 |
| --- | --- |
| 样本跳过标记 | P1：主平台指派样本加 `skipped` 状态端点；P0 仅前端本地跳过 |
| 任务内进度 | 现有快照/进度接口补"我的进度"字段（若缺） |
| 未读反馈数 | 现有通知接口加 `unread_return_count` 聚合（或前端拉取批注数） |
| 个人指标 | P1 新增 `/api/internal/portal/stats`（按 subject 聚合完成量/驳回率） |

## 7. 分期

- **P0（效率与反馈）**：工作台连续流 + 快捷键体系 + 帮助浮层 + 指南常驻栏 + 队列页反馈横幅/任务卡重构。纯前端 + 门户代理层微调，不动主平台契约。
- **P1（个人视角）**：仪表盘页 + 跳过回队尾（需主平台端点）+ 撤销历史侧栏 + 我的进度字段。
- **P2（治理）**：重做上限与申诉、入门 quiz、质量分联动。

## 8. 验收标准

- P0：纯键盘完成 20 样本连续标注无需鼠标；存在驳回时进入队列 3 秒内可见反馈入口；快捷键帮助浮层可用；既有测试（登录/队列/保存/批量/评论/退回）全部通过。
- P1：仪表盘指标与后端聚合一致（误差 0）；跳过样本重新出现在队尾且带标记。
- 通用：tsc、生产构建、既有 e2e（如涉及）通过；DEVELOPMENT_PLAN 记录。
