# 数据标注任务列表入口调整设计

## 目标

点击左侧“数据标注”后直接显示现有任务列表，移除任务列表页头中的“点焊标注任务”等标题和说明文字；保留“新建手动标注任务”“新建自动标注任务”以及任务列表内所有字段、状态和操作按钮文案。

## 范围与实现

- 修改 `frontend/src/pages/DataAnnotationPage.tsx` 的任务列表视图。
- 删除任务列表页头的产品/流程 kicker、页面标题和副标题。
- 保留创建任务操作，并将其放在任务列表内容顶部，不改变现有创建流程、URL 参数或权限判断。
- 不修改配置页、工作区、空状态文案、任务字段、状态标签和操作按钮。
- 默认 `/data-annotation` 路由继续由现有 `isTaskList` 判断进入任务列表；带有 `datasetId`、`runId` 或显式视图参数的旧链接继续按原逻辑工作。

## 验收与测试

- 默认进入 `/data-annotation` 后能看到任务列表区域和两个新建任务按钮。
- 页面不再渲染 `SPOT WELD / TASKS`、`点焊标注任务`、`查看任务状态、标注方式和当前进度`。
- 任务列表字段、状态、删除/打开等操作文案保持不变。
- 更新 `DataAnnotationPage.test.tsx` 中依赖旧页头的断言，新增页头文字不存在的回归断言。
- 运行数据标注页面聚焦 Vitest、前端 TypeScript/Vite 构建和 `git diff --check`。

## 非目标

- 不重构任务列表组件。
- 不改变后端 API、任务数据模型、路由协议或其他数据标注视图。
