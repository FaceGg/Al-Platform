# 通用数据标注任务与多标签标注设计

## 目标

重构数据标注页面，使“数据标注”菜单直接进入通用任务列表；手动标注和自动标注分别从任务列表创建，并统一支持多个独立标签列、样本级指派、预览、进度、标注员主动回传和管理员验收。

## 页面结构

### 任务列表

- 点击左侧“数据标注”直接显示当前项目的标注任务列表。
- “新建手动标注任务”和“新建自动标注任务”显示在任务列表右上角。
- 列表展示任务名称/编号、标注模式、数据文件、标签列、状态和标注进度。
- 不在创建页面提供“已有质量运行”选择器。

### 创建任务公共配置

- 移除“准备模拟数据”按钮。
- 移除行业专用配置和品牌标题区域。
- 移除“自动标注/手动标注”切换框；创建入口决定模式。
- 用户选择项目、数据文件和标签 schema 后才能开始任务。
- 标签 schema 中的每个列定义必填，支持两种来源：
  - 复用实际数据文件中的已有列（类型必须一致）；
  - 新建标签列名称和类型。
- 新建列名不能为空、不能与输入数据列或其他标签列重复、不能使用系统保留字段名。
- 自动标注的标签列不参与模型输入特征，避免标签泄漏；AutoML 的 target_columns 由建模任务合同单独定义。

## 手动标注

- 创建手动任务后，移除创建页规则配置。
- 点击“开始手动标注”后进入样本队列。
- 样本队列实时显示已标注数、总数和百分比，刷新来自任务状态接口。
- “样本详情”中人工标签区域置于最上方。
- 每个样本按标签 schema 保存多个独立标签列；每列按管理员选择的 int、float 或 string 校验，禁止数组型多选值。
- 保存使用 revision 乐观并发校验；过期修订返回冲突，只有标注员显式确认完整标签集合后才允许最后成功写入。
- 去掉“提交复核”按钮；标注员通过独立门户确认指派范围并主动回传，管理员在主平台回传结果列表中预览、批注、对比和验收。

## 自动标注

- 创建页去掉规则编辑、模拟数据、模式选择和已有运行控件。
- 增加模型选择器，候选项仅为当前项目模型库中的已注册模型。
- 自动标注只能选择按簇、按规则、按簇加规则中的一种；不启用聚类时使用模型输出，启用聚类时使用管理员配置的策略标签。
- 聚类使用所选模型的特征重要性加权 KMeans：重要性按目标列归一化并聚合，one-hot 映射回原始列，搜索 `K=2..8` 的 Silhouette Score，最终对全部合格样本赋簇；大数据使用确定性评估采样并记录样本数和 hash。
- 按簇必须配置不可删除的“其他”兜底；按规则必须配置其他规则；簇加规则按“规则 > 簇 > 其他”逐列决策，同优先级冲突进入待处理状态。
- 自动任务完成后停留在任务列表/预览上下文，不跳转详情；提供预览和多选指派标注员。

## 后端契约

- 创建任务请求新增并持久化：`label_schema_id`、标签列类型/约束、固定 sample_id 范围、自动标注模型 ID、策略、簇标签映射、规则、输入合同和 task revision。
- 任务、样本详情、导出数据和报告均使用实际标签列机器标识，不硬编码业务字段名。
- 标签接口提交完整标签集合和 `revision_no`；服务端执行项目范围、assignment 范围、状态和类型校验，删除标签使用显式清除操作。
- 模型必须校验项目归属、注册状态、模型制品可读性、输入输出合同和特征重要性可用性。
- 自动标注任务的长耗时聚类和推理继续通过现有异步任务执行，不阻塞请求。

## 错误处理

- 未选择数据文件、标签 schema 或模型时，禁止开始任务并显示字段级提示。
- 新建标签列与已有列重名时拒绝创建。
- 模型合同不匹配、重要性不可用或权重和为零、样本不足以搜索 K、策略冲突或兜底缺失时返回稳定错误码。
- 任务执行失败时保留任务和脱敏错误详情，前端显示失败状态，不能伪装为完成。

## 测试范围

- 前端：任务列表入口、两个创建入口、标签 schema、样本范围、手动和自动模式差异、预览、指派、冲突确认、批注和回传状态。
- 后端：标签列类型/约束、任务修订、assignment 范围、直接模型预测、特征重要性加权聚类、K 搜索、三种策略、并发回传和数据版本验收。
- 回归：通用数据导入、样本查询、标注导出、回传验收、权限和独立标注员门户测试必须继续通过。
