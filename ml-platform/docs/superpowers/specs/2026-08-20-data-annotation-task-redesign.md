# 数据标注任务与单标签标注设计

## 目标

重构数据标注页面，使“数据标注”菜单直接进入标注任务列表；手动标注和自动标注分别从任务列表创建，并统一支持必选目标列、单标签人工标注、样本进度和保存到数据管理。

## 页面结构

### 任务列表

- 点击左侧“数据标注”直接显示当前项目的标注任务列表。
- “新建手动标注任务”和“新建自动标注任务”显示在任务列表右上角。
- 列表展示任务名称/编号、标注模式、数据文件、目标列、状态和标注进度。
- 不在创建页面提供“已有质量运行”选择器。

### 创建任务公共配置

- 移除“准备模拟数据”按钮。
- 移除“点焊标注配置”和“SPOT WELD”标题区域。
- 移除“自动标注/手动标注”切换框；创建入口决定模式。
- 用户选择项目、数据文件和目标列后才能开始任务。
- 目标列为必选，支持两种来源：
  - 从实际数据文件列名中选择；
  - 新建目标列名称。
- 新建列名不能为空、不能与输入数据列重复、不能使用系统保留字段名。
- 目标列不参与模型输入特征，避免标签泄漏。

## 手动标注

- 创建手动任务后，移除创建页规则配置。
- 点击“开始手动标注”后进入样本队列。
- 样本队列实时显示已标注数、总数和百分比，刷新来自任务状态接口。
- “样本详情”中人工标签区域置于最上方。
- 每个样本只允许一个人工标签：
  - 选择标签会覆盖当前标签；
  - 删除标签会将目标列恢复为空/未标注；
  - 不保存标签数组，不支持多标签。
- 去掉“提交复核”按钮。
- 提供“保存到数据管理”按钮，将目标列写回导出数据。

## 自动标注

- 创建页去掉规则编辑、模拟数据、模式选择和已有运行控件。
- 增加模型选择器，候选项仅为当前项目模型库中的已注册模型。
- 增加“是否选择弱监督标注策略”：
  - 否：直接使用所选模型预测，预测类别使用目标列的标签类型；
  - 是：使用模型特征重要性加权 KMeans，并结合工艺规则生成标签。
- 弱监督策略使用所选模型的 `feature_importances_`：
  1. 获取 73 维权重向量；
  2. `weights = importances / sum(importances)`；
  3. `X_weighted = X_standardized * sqrt(weights)`；
  4. 在 `K=2..8` 搜索轮廓系数最高的 K；
  5. 使用最优 K 执行最终聚类。
- 聚类完成后显示簇结果，并要求用户添加标签。
- 标签数量默认不得少于聚类簇数量；每个簇至少需要一个标签映射。
- “点焊工艺规则模版”按钮自动添加可编辑的工艺规则项。
- 点击“开始自动标注”后，规则区域改名为“工艺规则”，只读展示，不能修改。
- 自动标注结果写入目标列，每个样本只保留一个标签。
- 样本详情人工标签置顶，支持覆盖和删除。
- 去掉“提交复核”按钮，保留“保存到数据管理”。

## 后端契约

- 创建任务请求新增并持久化：`target_column`、目标列来源/是否新建、自动标注模型 ID、弱监督开关、簇标签映射和工艺规则。
- 任务、样本详情、导出数据和报告均使用实际目标列名称，不硬编码 `Fault`。
- 手动标签接口继续使用单个 `label` 字符串；删除标签使用显式清除操作，不用空字符串模拟有效标签。
- 模型必须校验项目归属、注册状态、模型制品可读性和点焊 73 维特征模式。
- 自动标注任务的长耗时聚类和推理继续通过现有异步任务执行，不阻塞请求。

## 错误处理

- 未选择数据文件、目标列或模型时，禁止开始任务并显示字段级提示。
- 新建目标列与已有列重名时拒绝创建。
- 模型特征模式不匹配、缺少 `feature_importances_`、权重和为零、样本不足以搜索 K 时返回稳定错误码。
- 弱监督标签数量少于簇数量时拒绝开始自动标注。
- 任务执行失败时保留任务和脱敏错误详情，前端显示失败状态，不能伪装为完成。

## 测试范围

- 前端：任务列表入口、两个创建入口、创建公共字段校验、目标列选择/新建、手动和自动模式差异、单标签增删、规则只读、保存按钮和实时进度。
- 后端：目标列校验和持久化、单标签增删、模型项目范围、直接模型预测、特征重要性加权聚类、K 搜索、簇标签数量校验、目标列导出。
- 回归：现有点焊质量接口、样本查询、标注导出和保存到数据管理测试必须继续通过。
