# 手动标注任务状态展示设计

## 目标

数据标注页面中，手动标注任务对用户只展示“运行中”和“已完成”两种状态；自动标注任务保持现有状态展示不变。

## 方案

- 保留数据库、worker 和后端 API 中的真实状态，失败/取消等状态仍可用于诊断和底层控制。
- 在数据标注前端展示层增加按 `label_mode` 选择的状态归一化：手动任务已完成时显示“已完成”，其余状态显示“运行中”；自动任务继续使用通用状态标签和颜色。
- 应用于任务列表和任务工作区详情中的状态标签，不改变停止、删除、保存标注等行为判断。

## 验收

- 手动任务的 `running`、`queued`、`failed`、`cancelled` 等非完成状态均显示“运行中”。
- 手动任务的 `completed` 显示“已完成”。
- 自动任务的 `failed`、`cancelled` 等状态仍显示原有文案和颜色。
- 相关前端测试、生产构建和 `git diff --check` 通过。
