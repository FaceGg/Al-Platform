## 二、新建智能体任务（向导五步）

入口：智能体中心 → 新建任务。顶部配置条依次选择：项目=点焊、数据集=train_v2_full.csv、目标列=fault、模型=任一已配 Key 的档案、逐步确认模式=关。

### 第 1 步 数据分析

- **列清单**：勾选建模相关列。**务必丢弃组标识泄漏列**（与目标强相关但属标签泄漏，不剔会导致指标虚高、评审否决）：
  `organization_code / organization_name / area_code / area_name / line_code / workstaion_code / timername / wldindex / vin / vehiclecode / spot_code / weld_time / evaluecode / combinecode / robotcode / spotcode / visual_vin`
- **保留物理量**：`wld1c/wld1t/wld2c/wld2t/wld3c/wld3t/tipv1/capv1/ron1/tipv2/capv2/ron2/tipn/sch` 等
- **数据与训练真实性**：保持「全量数据训练」勾选（默认开）——验收指标 100% 对应全部 2180 行
- **分析提示词（推荐填一句）**：
  > 本域物理常识：焊接质量由能量与阻抗动态决定，允许并鼓励构造派生物理特征（电阻比、级间电阻差、能量密度），请把这些派生方向列入 S1 预期重要特征

### 第 2 步 特征工程

列级「数据类型」保持自动识别即可；泄漏列已在第一步标丢弃。

### 第 3 步 自动建模

- **算法白名单**：按需勾选（勾谁训谁；留空=全族搜索）
- **集成学习**：建议开启（top-K soft-voting，召回加权）
- 参数默认即可

### 第 4 步 评估验收

- 指标阈值：`recall_minority` 建议 **0.85～0.90**（注意：引擎 3 折交叉验证口径比单切分严格，设 0.95+ 容易验收不过）
- 评审重点可留空

### 第 5 步 启动与服务化

- **「启动智能体」**：只跑建模验收，服务化稍后在任务档案页操作（本指南走这条）
- **「启动并服务化」**：验收通过后自动接力（需项目已有 running 部署）

点击后自动迭代：S1 数据分析 → S2 特征工程（沙箱验证）→ S3 全量训练 → S4 硬门禁+LLM 评审 → **accepted**（1 轮收敛为正常；若评审升级，按档案里的 hints 调整后重提）。

## 三、一键部署（任务详情页 · 服务化操作流）

入口：任务列表 → 点开 accepted 任务 → 滚动到「服务化操作流」（分步进度条，每步 25%）。

| 步骤 | 操作 | 说明 |
|---|---|---|
| ① 固化配方 | 点一下（本例已自动固化则显示 recipe ✓） | 验收成果固化为配方 v1，含特征脚本/门禁/白名单/集成/重放快照 |
| ② 直接部署本次模型（秒级） | 点一下，等 ✓ 新部署已就绪 | S3 冠军模型注册 → ONNX 转换 → 批准 → **新建 running 部署**，全自动；实测 2.3 秒 |
| ③ 一键服务化（草稿+冒烟） | 点一下 | 自动起草三资产并冒烟验证（dry_run 零回流），显示草稿就绪信息 |
| ④ 批准发布 | 勾选目标（默认全选）→ 点一下 | **API+闭环任务**（市场上架、回流重训激活）+ **应用编排**（实例化闭环模板，发布可编排 API） |

> 每步 25% 进度；当前步蓝色、进行中转圈、后续步灰色；完成自动进入下一步。
> 退出重进页面会自动恢复到当前进度，不会丢状态、不会重复建任务。

## 四、发布后的闭环（自动运行）

- **API 调用**：API 市场 → 「智能体闭环」条目 → 调用示例；报错行自动回流
- **自动重训**：回流行达阈值（默认配置可在闭环「编辑配置」调整）→ 触发智能体重训（配方重放 → S4 验收 → 引擎铸造 → 自动换模）；含单飞/冷却/24h 熔断护栏
- **监控大屏**：闭环详情页右上「运行监控大屏」——实时动画展示 推理→回流→告警→智能体重构→特征工程/模型替换 全链
- **换模跟随**：闭环重训换模后，API 与编排调用自动用到新模型，零重发布

## 五、常见问题

| 现象 | 处理 |
|---|---|
| 验收升级（REVIEW_ESCALATE / MAX_ROUNDS） | 看档案 review/hints：多为泄漏列未剔或门禁过高——按上面第 1/4 步调整后重提 |
| ② 报「未物化 S3 冠军」 | 该任务为旧版本创建（无工件）；重提一个新任务即可 |
| ③ 报 already published | 该部署已发布过——刷新页面会显示 100% 已发布，无需重复操作 |
| 大屏节点显示「自动建模」 | 底部「重训」切换到「智能体」（实时连接后自动跟随任务配置） |
