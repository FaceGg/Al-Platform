## 一、演示前准备清单（约 10 分钟）

### 1.1 启动环境

```bash
# Windows 终端执行（保持窗口不关，防止 WSL 空闲关停杀容器）
wsl -e bash -lc "sleep 14400" &
# 另开窗口
cd E:\codex_workspace\agent_spot_welding
wsl -e bash -lc "cd /mnt/e/codex_workspace/agent_spot_welding && docker compose up -d"
# 等 1 分钟后验证
curl http://localhost:8001/api/health     # {"status":"ok"}
curl http://localhost:5173/ -o /dev/null -w "%{http_code}"   # 200
```

> 故障：Windows 访问 localhost 返回 000 而 WSL 内 200 → `wsl --shutdown` 后重跑上面两条。

### 1.2 登录主平台

浏览器打开 http://localhost:5173 → admin / admin123 → 登录。
（旧版页面打不开新功能时按 **Ctrl+F5** 强刷。）

### 1.3 确认四项前置条件

| # | 检查项 | 在哪看 | 要求 |
|---|---|---|---|
| 1 | 推理部署运行中 | 模型库 → 部署（如部署 "11"） | 状态 运行中 |
| 2 | 标注员可用 | 数据标注 → 标注员管理 | jing 已启用、已授权点焊项目 |
| 3 | 重训数据集存在 | 数据管理 → 项目数据集 | labeled_features-恢复（含 fault 列） |
| 4 | 演示 CSV 就绪 | 本机 `ml-platform/backend/uploads/labeled_features_demo.csv` | 46 行真实特征数据（73 特征 + fault） |

### 1.4 复制 Token（大屏实时模式用）

1. 在主平台页面按 **F12** → **Console**；
2. 输入 `copy(localStorage.getItem("token"))` 回车 → Token 已进剪贴板；
3. 粘贴保存备用（跨浏览器打开大屏时需要；同浏览器则自动读取）。

## 二、方案 A：闭环演示页（核心演示，约 8 分钟）

地址：**http://localhost:5173/closed-loop-demo**

### 2.1 配置闭环（首次或检查）

| 配置项 | 演示建议值 | 说明 |
|---|---|---|
| 推理部署 | 部署 11 | 逐行预测走它的真实模型 |
| 报错类别 | 1 | 预测=1 的行判定为报错行 |
| 告警阈值 | 2 | 每 2 行报错触发一次管理员告警 |
| 自动特征工程 | 开 | 原始报告行自动补齐 73 特征 |
| 人工审核 | 开 | 告警自动创建标注任务 |
| 审核标注员 | jing | 告警后自动分配 |
| 自动重训 | 开 | 积累触发 AutoML |
| 重训触发行数 | 3 | 报错积累 3 行触发建模 |
| 重训数据集 | labeled_features-恢复 | AutoML 的训练数据 |
| 重训目标列 | fault | 分类目标 |
| 试验次数 | 5~10 | 越大越慢越优 |

**点「保存配置」**（开关改动必须保存才生效；「开始演示」会自动保存当前表单）。

### 2.2 数据回放（全闭环真实运行）

1. 点「上传 CSV」→ 选择 `labeled_features_demo.csv`；
2. 点「**开始演示**」→ 页面逐行真实调用推理 API：
   - 每行显示预测类别 + 置信度；
   - 预测=1 的行标红「已回流」→ 真实写入报错数据集；
   - 每达告警阈值 → 管理员告警 + 站内通知；
   - 报错积累到重训阈值 → **自动触发 AutoML**（约 90 秒）→ 完成后自动换模型（事件流提示「推理模型已替换」）。

### 2.3 六个环节的效果在哪看

| 环节 | 演示时看 | 事后查 |
|---|---|---|
| ① 逐行预测 | 页面行卡片（预测类别/置信度） | API 市场 → 模型 API 调用数 +1 |
| ② 错误回流 | 红色「已回流」标记 | 数据管理 → 闭环演示-报错数据 行数增长 |
| ③ 阈值告警 | 告警横幅 + 计数 | 右上角铃铛 → 站内通知 |
| ④ 人工审核 | 提示已创建任务 | 数据标注 → 出现「闭环演示-人工审核-N」；标注员 jing 登录门户可处理 |
| ⑤ 自动重训 | 事件流「自动建模任务已触发」 | 自动建模页 → 新 AutoML 任务 90 秒完成 |
| ⑥ 模型替换 | 事件流「推理模型已替换」 | 模型库 → 部署 11 指向新模型版本（可回退） |

### 2.4 重置

演示完点「重置闭环」：清空计数/事件（保留配置与报错数据文件）。

## 三、方案 B：应用编排 → API 市场（约 8 分钟）

### 3.1 新建服务图

导航「**应用编排**」→ 选项目（点焊）→ 点「**新建编排**」→ 填名称（如"焊接质量推理服务"）→ 创建后自动进画布。

### 3.2 搭建全闭环服务图

从左侧算子面板拖入以下节点并连线：

| 算子（面板分类） | 节点作用 | 关键参数 |
|---|---|---|
| API 输入（数据输入输出） | 接收逐行调用 | 无 |
| 冻结模型/加载模型制品 | 绑定已训练模型 | model_artifact_id = 模型制品 ID |
| 应用模型（传统机器学习） | 推理 | 无（模型口接冻结模型） |
| 条件分支（流程控制） | 分类判断 | column=prediction, operator===, value=1 |
| 追加报错数据集（数据输入输出） | 报错行回流 | dataset_artifact_id = 报错数据集制品 ID |
| 告警通知管理员（数据输入输出） | 站内告警 | title/message 自定义 |
| 重训阈值判断（流程控制） | 积累判断 | dataset/retrain_dataset/目标列/阈值/swap_deployment_id |

连线：**API 输入 → 应用模型（data 口）；冻结模型 → 应用模型（model 口）；应用模型 → 条件分支；条件分支 true_branch → 追加报错数据集 → 告警通知管理员 → 重训阈值判断**。条件分支 false_branch 即正常行出口。

> ⚠️ 发布门禁：服务图必须含 API 输入 + 应用模型，**禁止训练/搜索算子**（模型用「加载模型制品」冻结绑定，训练与服务分离）。

### 3.3 发布到 API 市场

点画布顶部「**发布为 API**」→ 保存 → 发布版本 → 注册编排 API，三步一气呵成。
- 门禁拦截时 toast 会说明原因（如缺少 API 输入节点）→ 按提示改图；
- 成功 toast 显示「已发布为编排 API：{名称} v{N}」。

### 3.4 API 市场管理

导航「**API 市场**」→「Orch. API」筛选：
- 每条编排 API 可 **详情 / 测试 / 下线（暂停）/ 删除**；
- 模型 API（部署自动生成）不可删——由部署生命周期管理；
- Calls / Success Rate 列实时累计。

### 3.5 通过市场调用（逐行真实推理）

**程序化调用**：
```
POST /api/platform/apis/orchestration/{版本ID}/invoke
Authorization: Bearer {token}
{"record": { ...单行 73 特征... }}
→ 返回 {"records": [...], "branch": "true|false"}
```

**市场页测试面板**：详情 → 测试 → 粘贴单行 JSON → 发送。

调用计数实时累计；工作流删除时编排 API 自动下线。

## 四、大屏动画演示（收尾，约 3 分钟）

地址：**http://localhost:5173/demo-showcase.html**（新标签页，无需登录）

## 五、常见问题与排除

| 现象 | 原因 | 处理 |
|---|---|---|
| 创建按钮一直转圈、关闭没反应 | 旧版弹窗 bug（已修复） | Ctrl+F5 强刷加载新版 |
| DEMO_LOOP_RECORD_INVALID 缺少特征列 | CSV 缺模型特征列 | 开自动特征工程 + 确保含波形列；或用已做特征工程的数据集 |
| DEMO_LOOP_RECORD_INVALID 值不是数值 | CSV 某列非数值 | 检查数据质量 |
| 模型制品文件缺失 | 存储卷重建丢文件 | 报错数据集自动自愈；模型需重训或指回完好版本 |
| 全部容器消失 | WSL 空闲关停 | `docker compose up -d` 恢复（数据卷保留） |
| localhost 打不开但 WSL 内正常 | localhost 转发失效 | `wsl --shutdown` 后重启栈 |
| CORS_ORIGIN_FORBIDDEN | 用了 127.0.0.1 访问 | 改用 http://localhost:5173 |
| 重训报 registered_models 唯一冲突 | 旧版 bug（已修复） | 升级后每轮重训模型名带周期后缀 |
