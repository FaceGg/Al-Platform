# 闭环系统演示操作手册

> 前提：docker compose 全栈运行中（`docker compose up -d`），后端 8001 / 前端 5173 正常。
> 演示账号：admin / admin123（浏览器访问 http://localhost:5173 登录）。

---

## 〇、演示前准备（一次性，约 5 分钟）

### 0.1 确认推理部署在运行

1. 打开 **模型库 → 模型训练 / 部署** 页
2. 确认目标部署（如部署 "11"）状态为 **运行中**
3. 记录部署的 **模型制品 ID**（模型库中该版本对应的模型制品，方案 B 服务图需要）
4. 记录模型特征列数（如 73 特征）和输出类别（如 0/1）

### 0.2 确认标注员可用

1. 打开 **数据标注 → 标注员管理**（或管理员门户）
2. 确认至少一名标注员状态为 **已启用** 且已被授权到演示项目（如 jing → 点焊）

### 0.3 确认重训数据集存在

1. 打开 **数据管理**，确认项目内有一份带标签列的数据集（如 labeled_features.csv，含 fault 列）
2. 记录数据集名称和目标列名（如 fault）

## 一、方案 A：闭环演示页（约 5 分钟）

> 地址：http://localhost:5173/demo-loop

### 1. 配置闭环

1. 选择项目（点焊）
2. 选择**推理部署**（如部署 11）
3. 填写**报错类别**（如输入 `1`，回车；命中该类别的行会回流）
4. 设置**告警阈值**（如 2：每 2 行报错触发一次告警）
5. 打开**自动特征工程**开关（上传原始报告数据时自动补齐 73 特征）
6. 打开**人工审核**并选择标注员（如 jing）
7. 打开**自动重训**：
   - 重训触发行数：如 3
   - 重训数据集：选择带标签列的数据集（如 labeled_features.csv）
   - 目标列：如 fault
   - 搜索试验次数：5（演示时用小值加快速度）
8. 点「保存配置」

> ⚠️ 开关改动必须点「保存配置」才生效；「开始演示」时会自动保存。

### 2. 数据回放

1. 点「上传 CSV」，选择数据文件：
   - **含波形列**（cvei/cvev/cver/cvep）的原始报告 CSV → 自动特征工程会补齐 73 特征
   - 或已做过特征工程的 73 列数据集 CSV → 开不开开关均可
2. 点「开始演示」→ 逐行调用推理 API，页面实时展示：
   - 每行预测类别 + 置信度 + 是否回流（绿色正常 / 红色命中报错）
   - 进度条与告警横幅（脉冲动画）
   - 错误数据计数器增长

### 3. 验证闭环副作用（演示时同步展示）

| 现象 | 在哪里看 |
|---|---|
| 错误数据回流 | **数据管理**：报错数据文件行数增长 |
| 管理员告警 | 右上角**通知中心**（铃铛）出现告警通知 |
| 人工审核任务 | **数据标注**页面出现「闭环演示-人工审核-N」任务，标注员 jing 可在门户看到并处理 |
| 自动建模触发 | **自动建模**页面出现 AutoML 任务（状态从排队→执行中→完成） |
| 模型替换 | AutoML 完成后，事件流出现「推理模型已替换」，模型库中部署指向新模型版本 |

### 4. 重置

演示完毕点「重置闭环」清空计数与事件（保留配置与数据文件）。

## 二、方案 B：应用编排 → API 市场（约 5 分钟）

> 地址：画布 http://localhost:5173/workspace/{workflow_id}（从项目详情进入或新建）

### 1. 搭建服务图（全闭环一张图）

在画布中拖入以下算子并连线：

```
API 输入 (api_input)
    ↓ data
应用模型 (apply_model) ←──── 冻结模型 (load_model_artifact)
    ↓ data                    │ model
条件分支 (condition)          │    参数：模型制品 ID
    ├─ true_branch ──→ 追加报错数据集 (append_error_dataset)
    │                      ↓ data
    │                  告警通知管理员 (notify_admins)
    │                      ↓ data
    │                  重训阈值判断 (retrain_threshold)
    │                      ├─ triggered（AutoML 已触发，完成后自动换模型）
    │                      └─ continue（未达标，继续积累）
    └─ false_branch ──→（正常行结束）
```

**各算子参数**：

| 算子 | 关键参数 |
|---|---|
| load_model_artifact | model_artifact_id = 部署模型对应的制品 ID |
| condition | column = prediction, operator = ==, value = 1（报错类别） |
| append_error_dataset | dataset_artifact_id = 报错数据集制品 ID |
| notify_admins | title = 报错告警, message = 错误数据已回流 |
| retrain_threshold | dataset_artifact_id = 报错数据集制品 ID, retrain_dataset_artifact_id = 重训数据集制品 ID, retrain_target_column = fault, threshold_rows = 3, retrain_max_trials = 5, swap_deployment_id = 部署 ID |

> **load_model_artifact** 用于绑定已训练好的模型（训练/服务分离）；**特征工程算子**（可选）可插在 api_input 和 apply_model 之间。

### 2. 发布为 API

1. 点画布顶部**「发布为 API」**
2. 系统自动：保存草稿 → 发布版本 → 注册编排 API
3. 成功提示「已发布为编排 API，可在 API 市场查看」

### 3. API 市场管理

1. 打开 **API 市场**，用「Orch. API」筛选查看编排 API
2. 展示：紫色 Orch. 徽标、版本、Published 状态、调用计数
3. 演示操作：
   - **测试**：点测试面板发一条数据验证
   - **下线**（暂停服务）→ 再重新发布（恢复）
   - **删除**：清理由演示产生的测试 API

### 4. 通过 API 调用

- **程序化调用**（POST）：
  ```
  POST /api/platform/apis/orchestration/{版本ID}/invoke
  Authorization: Bearer {token}
  Content-Type: application/json

  {"record": { ... 单行特征 ... }}
  ```
  返回 `{"records": [...], "branch": "true|false"}`

- **逐行演示**：上传 CSV 后在闭环演示页逐行调用（与方案 A 共用数据回流链路）

## 三、大屏演示页（约 2 分钟，收尾）

> 地址：http://localhost:5173/demo-showcase.html（无需登录，新标签页打开）

1. **演示模式**：自动剧本播放——粒子沿数据流管线跑，报错行红色回流，告警脉冲，重训进度环充满后自动换模型（v1→v2 金色弧线），HUD 准确率上升

3. 演示控件：暂停 / 重置 / ×1×2×4 倍速
4. 也可从闭环演示页顶部「大屏动画演示」按钮直达

## 四、演示亮点话术

| 演示节点 | 讲什么 |
|---|---|
| 数据上传 + 逐行调用 | 每行数据独立调用推理 API，与生产推理路径完全一致 |
| 特征工程算子 | 原始波形自动解码为 73 维特征，训练与服务用同一套特征定义 |
| 条件分支 | 命中报错类别的行自动分流到回流路径 |
| 错误数据回流 | 报错行自动写入数据管理的报错数据集，持续积累 |
| 阈值告警 | 达到阈值自动通知管理员（站内信 + 大屏脉冲） |
| 人工审核 | 自动创建标注任务并分配标注员，标注员门户可看到 |
| 自动建模 | 积累到阈值自动触发 AutoML，最优候选自动注册 |
| 模型替换 | 新模型自动上线替换旧模型，下次调用即用新模型 |
| 大屏 | 全流程节点动画 + 实时数据联动 |

## 五、常见问题与排除

| 现象 | 原因 | 处理 |
|---|---|---|
| DEMO_LOOP_RECORD_INVALID 缺少特征列 | 上传数据缺模型特征列 | 打开自动特征工程开关 + 确保数据含波形列；或改用已做过特征工程的数据集 |
| DEMO_LOOP_RECORD_INVALID 值不是数值 | CSV 某列有非数值内容 | 检查数据质量 |
| DEMO_LOOP_CONFIG_NOT_FOUND | 项目尚未配置闭环 | 保存配置后自动创建 |
| 触发了 mlflow filestore 错误 | 本地模式未配 MLFLOW_TRACKING_URI | 生产/部署模式不受影响（走 mlflow 服务） |
| 容器整组退出 | WSL 空闲自动关停 | docker compose up -d 恢复 |
