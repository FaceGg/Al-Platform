### 2.3 启动闭环（全流程真实运行）

2. 点「**启动闭环**」→ 逐行真实调用推理 API：

### 2.5 关键设计规则（演示可讲）

- **报错数据单文件追加**：每任务的报错数据持续追加到它自己专属的一个文件，不新建文件、不跨任务混写；
- **单一审核任务**：每任务同一时间只有一个进行中的审核任务——未完成时新报错继续累积（事件流提示"任务仍在进行中"），完成后下一轮告警才建新的；
- **状态自愈**：取消/失败/完成自动建模后任务自动回到可触发状态（曾取消过一次也不会卡死）；
- **多数据集合并重训**：所选数据集按选择顺序合并为「合并数据集」训练，列体系不一致时自动取交集保行数；
- **回流数据自动打标签**：回流行落盘自带 fault=预测类别，历史无标签回流文件在合并时用 prediction 列补齐。

### 2.6 重置

详情页「**重置闭环**」：清空计数/事件/换模水印（配置与报错数据文件保留）。演示第二轮前建议先重置。

- 模型 API（部署自动发布）在市场无删除按钮——生命周期归模型库，删除部署时市场行自动清理。

## 六、常见问题与排除

| 现象 | 原因 | 处理 |
|---|---|---|
| 列表显示"暂无闭环任务" | 任务被删除 | 「新建闭环」重建即可（报错数据文件保留） |
| 注册版本报 MODEL_CONVERSION_UNSUPPORTED | 对普通训练条目注册（sklearn/SGD 不支持 ONNX 转换） | **必须从自动建模任务的结果表点「注册」**，再对该注册模型建版本 |
| 报错类别输入后提示必填 | 值未提交成标签 | 输入数字后按 **回车** 使其变成标签 |
| 页面没有新功能 | 浏览器缓存旧版 | Ctrl+F5 强刷（服务端已强制 no-cache，一般无需） |
| 登录/接口 502 | backend 容器刚重建，frontend 内 nginx 缓存旧 IP | `docker compose restart frontend nginx` |
| DEMO_LOOP_RECORD_INVALID 缺特征列 | CSV 缺模型特征列 | 开自动特征工程并含波形列，或用 73 特征体系 CSV |
| 重训报"数值特征不足 10 行" | 所选数据集与回流行**列体系不一致** | 重训数据集与演示 CSV 选同一体系（labeled_features.csv） |
| 重训报"目标列 fault 不在数据集中" | 数据集缺目标列且无推理结果可补 | 确认目标列拼写；选含 fault 的基础数据集 |
| 取消自动建模后不再触发 | 旧版卡死（已修复） | 现自动恢复：取消后状态自愈回可触发，无需处理 |
| 审核任务一直不新建 | 设计行为：进行中的任务不重复创建 | 完成当前任务后下一轮告警自动再建 |
| 方案 B 建模完成后部署没变 | 设计行为：调用时闭环 | **再调用一次**任意行，换模在下次调用中自动完成 |
| 方案 B 响应 branch 为 null | 输出节点是重训阈值判断（无真假端口） | 正常；回流判断在条件分支节点，看 records 即可 |
| 部署删除后市场仍显示 | 旧版孤儿行（已修复） | 现删除部署自动清理市场行 |
| 模型制品文件缺失 | 存储卷曾被重建 | 报错数据集自动自愈；模型重训或指回完好版本 |
| 全部容器消失 | WSL 空闲关停 | `docker compose up -d` 恢复（数据在命名卷） |
| localhost 打不开但 WSL 内正常 | localhost 转发失效 | `wsl --shutdown` 后重启栈 |
| CORS_ORIGIN_FORBIDDEN | 用了 127.0.0.1 访问 | 改用 http://localhost:5173 |
