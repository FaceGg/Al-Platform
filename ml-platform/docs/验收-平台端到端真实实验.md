## 口径与解读

- 正常行 1,836 < 判据①门槛 10,000——**小样本端到端机制复证，非判据①正式达标**（正式达标待 ≥1 万行真实点焊历史数据）
- 与离线脚本对照（验收-点焊真实数据.json，同数据同特征）：平台链路 ocsvm synthetic_auc 0.9889 vs 离线 0.9930（采样与随机性差异内一致）；冠军族一致（ocsvm）
- 真实异常检出对照（离线脚本口径）：ocsvm 75.8% / AE 57.6% / iforest 46.2%——真实异常形态与合成构造形态显著不同（详见同目录验收-点焊真实数据.json 的解读段）
