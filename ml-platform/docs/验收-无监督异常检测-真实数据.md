- 结论：**iforest 与 ocsvm 双双通过全部门禁**（synthetic_auc ≥ 0.85、normal_fpr ≤ contamination×1.5、stability ≥ 0.8），冠军排序将取 ocsvm（三类检出全面占优）
- 结果数据：[验收-无监督异常检测-真实数据.json](验收-无监督异常检测-真实数据.json)

## 方法与口径

- **数据**：拧紧历史数据 `tighten_train_clean.csv`（28.0 万行）；按「只用正常数据训练」的核心语义取判定列 `DECIDE_ONE == 1`（合格）样本 **222,942 行**
- **特征**（5 数值列）：TARGET_TORQUE / UPPER_LIMIT / LOWER_LIMIT / ACTUAL_TORQUE / PROGRAM_NO
- **采样**：12,000 行（固定种子 42）——OC-SVM 训练成本与评估耗时可控
- **评估**：引擎核心（automl_anomaly）按生产同路径执行——80/20 分割（9,600 训练 / 2,400 保留集）→ 三类合成异常注入基准（均匀外点 / ±1.5σ 局部扰动 / 分位错配组合异常，与保留集 1:1 封顶 2,000/类）→ contamination=0.01 标定阈值（保留集分位）→ 双族完整评估（含 5 次子采样重训 Spearman 稳定性）
- **可复现**：`ml-platform/backend/tools/acceptance/run_anomaly_real_data.py`（数据路径参数化；数据文件不在仓库内，换机器跑需提供同口径 CSV）

## 结果

| 指标 | 门禁 | iforest | ocsvm |
|---|---|---|---|
| synthetic_auc（主排序键） | ≥ 0.85 | **0.9612** ✓ | **0.9930** ✓ |
| normal_fpr（保留集误报率） | ≤ 0.015 | 0.0104 ✓ | 0.0100 ✓ |
| stability（5 次子采样 Spearman） | ≥ 0.8 | 0.9950 ✓ | 0.9999 ✓ |
| 检出率·均匀外点 | — | 0.187 | 1.000 |
| 检出率·局部扰动（最难形态） | — | 0.016 | 0.968 |
| 检出率·组合异常 | — | 0.000 | 0.795 |
| 门禁结论 | 全过才可为冠军 | **通过** | **通过（冠军）** |

## 解读

1. **ocsvm 全形态占优**：三类合成异常的检出率（1.0/0.968/0.795）显著高于 iforest——真实拧紧数据的核方法对联合分布的刻画能力强于轴平行切分；冠军排序按 synthetic_auc 主键将取 ocsvm。
2. **iforest 的组合异常检出为 0**：轴平行切分对「盒角密度空洞」不敏感（与合成基准构造迭代时的实测一致），这也是冠军排序存在的意义——同台对比后自动选优，而非假设某一族万能。
3. **误报自洽**：两族 normal_fpr 均落在 contamination×1.5 门禁内（≈contamination 本身），阈值标定口径（保留集分位）在真实数据上成立。
4. **判据④（误报率较阈值基线下降 ≥30%）**：需真实部署后的长周期报警确认数据，一期以「PSI 预警自动触发重拟合 + 重拟合仅用正常数据 + detection_retention 换模门禁」机制闭环交付（M4）。
