## 4. 过程中发现并修复的缺陷

1. **合并环**：celery `acks_late` 在 WSL 崩溃重启后重投任务，二次 fuse 在交错状态下写出 A→B→A 互相 merged_into 的环+悬挂边 → `merge_entities` 增加 winner 链解析环保护；`GET /graph` 边查询增加悬挂边过滤（端点必须存活）。
2. **RouteOutlined 图标不存在**（当前 @ant-design/icons 版本）→ NodeIndexOutlined。
3. **归一化语义分裂**：旧 `_normalize_name` 仅小写 ASCII casefold → 统一委托 `kg_names.normalize_name`（含大写）。
