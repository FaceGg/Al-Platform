## 4. 未验证与遗留

- **environment-blocked**：竞品同口径数据复算（口径 1，D42）——数据集未随简报提供。
- **not_run（浏览器）**：SPC 控制图 / 直方图的真实渲染、漂移页明细弹窗——前端用例运行在 jsdom，图表为替身组件；只验证了结构、载荷与交互逻辑。
- **not_run（调度）**：Celery beat `drift-scan` 的真实巡检节奏未在运行栈验证（只验证了任务体 `run_drift_scan`）。
- **not_run（数据库）**：PostgreSQL 上 `_111` 的往返由 CI 生产集成作业背书。
- **not_run（通道）**：严重级通知经钉钉 / 短信 / 邮件的真实送达需现场凭据（站内信已实测）。
- **设计限界（D39 如实登记）**：①PCA 重构误差未实现（平台不保存全量特征向量）；②分数级 PSI 未并入漂移报告（闭环内独立运行）；③分片部署按部署主版本合并统计，分片间差异被平均；④预警中心跳回 SPC 页只做到按来源筛选的列表级，未做带点位参数的深链；⑤基线首次惰性计算会在该版本第一笔落库的后台线程里多花数秒读取训练数据。
- **实施记录（§9C.5）**：测试拦下并修复「实时 3σ 判异重复传参」——保存点兜住了落库，但该次请求整段预警评估被撤销；已修并有回归用例。
- **安全扫描**：提交时安全扫描器多次未给出完整结论（`scanner_enobufs`），本验收不据此宣称项目安全。
