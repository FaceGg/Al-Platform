# 平台说明文档

本文档覆盖三大部分：**主平台**（面向工程师/管理员的 ML 全流程平台）、**标注员门户**（面向标注员的任务执行端）、**管理员审核门户**（管理员在标注员门户内以管理员身份登录后使用的验收审核端）。

主平台中「应用编排」「API 市场」「知识库」「知识图谱」「AI 对话」五个模块以及「模型库」中的推理部署为二阶段规划功能，当前版本暂未实现，详见 2.14 节。

## 2.5 数据标注

结构化数据标注的核心模块，包含四个形态：任务列表（默认）、创建向导（手动/自动）、旧版创建、手工标注工作台。

### 2.5.1 任务列表视图
**页头**：项目下拉（全部项目）+ **新建手动标注任务** + **新建自动标注任务** 按钮。

**统计卡**（4 张）：进行中任务、待配置策略（聚类预览已完成）、待验收回传、运行中操作。

**任务视图 Tab**：全部任务 / 进行中 N / 历史任务 N。

**通用任务表格**（全部/进行中 Tab）：列＝任务（名称+短 ID+模式）、状态、样本数、创建时间、截止时间、修订号、操作。底部**加载更多任务**（游标分页）。
行操作：
- **预览**：打开预览抽屉（见 2.5.4）。
- **指派标注员**：仅状态为 预览就绪/待标注/进行中 时可用，否则禁用并提示原因；打开指派弹窗（见 2.5.5）。
- 状态流转按钮（按状态动态出现）：
  - **编辑任务**（草稿/失败/待复核）
  - **重新生成预览**（草稿/失败）
  - **配置策略**（自动任务+待复核）
  - **批注管理**（任意状态）
  - **暂停**（预览就绪/执行中/待标注/进行中/待回传）
  - **恢复**（已暂停）
  - **取消**（多数非终态）
  - **提交回传**（待回传）
  - **验收**（待验收）、**完成**（已验收）
  - **归档**（已验收/已完成/已取消）、**恢复归档**（已归档）、**重开**（已完成）
- **删除**（二次确认）。

**历史任务表格**（全部/历史 Tab）：旧版点焊质量任务，列＝任务、项目、创建者、模式/状态、进度；操作**查看标注**（进工作台）与**删除**。

**任务操作记录区**：标题 + **刷新操作**按钮；操作卡片显示操作 ID、状态、资源类型/阶段、所属任务、进度条、时间、错误码；执行类操作完成后出现**查看结果**按钮，打开执行结果抽屉：按 sample/cluster/rule/final_label 四个维度切换统计，结果表（样本、序号、状态、最终标签 JSON、来源 JSON）+ 统计表 + **加载更多结果**。

**版本冲突弹窗**：任何操作遇到 409 时展示服务端最新修订与标签，可**确认并覆盖**。

**回传验收面板**（选中项目后页面底部显示，样式与任务操作记录一致）：
- 卡片网格：任务名（代码样式）、回传状态标签、标注员·样本数、任务 ID、时间。
- **打开验收**（待验收批次）→ 验收抽屉：概要（任务/标注员/批次状态/样本数/修订）、质量风险（空标签计数）、**在标注员门户查看明细**按钮（新窗口打开）、退回原因输入、**验收并生成数据版本** / **退回修改** 两个按钮。
- 已验收批次提供**保存到数据管理**：输入数据集名称→**检测标签并保存**（文本型标签展示值→整数映射表）→**确认映射并保存到数据管理**。
- 面板头**刷新**按钮；**加载更多**批次。

### 2.5.2 新建自动标注任务（两步向导）
顶部步骤条：基本信息 → 标注规则。右上**返回任务列表**。

**第 1 页（基本信息）**字段：
- 任务名称（必填，≤200 字）；项目（必选）；
- 数据版本（下拉显示 源文件·vN·行数·列数）；
- 已启用模型版本（下拉；不可用版本带禁用原因：未审批启用/仅支持平台 joblib 产物/输出合同不可用）；
- 冻结标签合同（选中模型后只读展示输出列 机器键·名称·类型）；
- 样本范围：全量样本 / 按条件筛选（筛选条件＝字段+运算符[等于/不等于/大于/大于等于/小于/小于等于/为空/非空]+值，多条件 AND，可增删）；
- 可见字段（数据版本列复选，至少 1 个）；
- 标注说明（多行）、完成标准（多行）、截止时间（日期，默认 7 天后）。
- **下一页**按钮（上述必填项不全时禁用）。

**第 2 页（标注规则）**：
- **是否启用弱监督标注**：否（直接使用模型原始输出，标注员可修改确认）/ 是（先聚类，再按策略生成标签）。
- 弱监督=否：直接**创建通用任务**并自动生成最终预览，完成后回任务列表。
- 弱监督=是（簇发现模式）：
  - **生成聚类预览**按钮：创建任务并聚类（加权 KMeans、轮廓系数选 K），期间显示进度，失败可**重试聚类预览**。
  - 聚类完成后：**簇预览**（簇占比条形图、PCA 散点预览、评估指标、K 分数曲线）与**自动标注策略编辑器**（策略：按簇/按规则/簇加规则；每簇标签映射；规则行[优先级/AND-OR 条件组/条件字段/运算符/比较值/命中标签值/簇过滤]；其他兜底值；类型与完整性实时校验）；**标签列定义**（机器键只读、标签名称、值类型[字符串/整数/浮点数]、约束方式[枚举值/范围/枚举值且范围]、枚举值/最小最大值、列说明；**添加列**/**保存 schema**）与**策略库**（**保存策略**：命名保存当前策略供复用；**导入策略**：选择已保存策略载入）。
  - **保存策略并完成**按钮：校验通过后保存配置并自动生成全量最终预览；就绪后任务自动开始执行，页脚变为**返回任务列表**。
- 常驻**冻结契约摘要**侧栏：展示第 1 步锁定的任务名/数据版本/模型版本/样本范围/输出列。
- 任务重名时服务端自动改名并提示。

### 2.5.3 新建手动标注任务（单页表单）
字段：任务名称、项目、数据版本、标签方案名称（默认 labels）、标签字段（默认 label）、标签类型（字符串/整数/浮点数）、填写指引、样本范围（全量/按条件筛选）、可见字段、标注说明、完成标准、截止时间。
**创建通用任务**按钮：先创建标签 schema 再创建任务，并自动生成预览，提示后回任务列表。
（另存在旧版点焊手动创建视图：项目+数据文件[或上传 CSV/XLS/XLSX]+目标列[选已有列/新建列]+标签列定义，**开始手动标注**按钮校验数据后进入工作台。）

### 2.5.4 预览抽屉
- 点击遮罩或 × 关闭；状态徽标（排队中/处理中/已完成/失败等）+ 百分比 + 进度条；每秒轮询。
- 指标：样本总数 / 已加载 / 可见字段数。
- 区块：错误提示、聚类预览（簇占比/散点/指标）、任务快照（说明/数据版本/数据范围/可见字段/标签 schema/模型配置/配置 hash）、结果摘要 JSON、策略摘要 JSON、预览样本列表（sample_id+行号+values JSON，**加载更多**每批 50 条）。

### 2.5.5 指派标注员弹窗
- 概要：任务修订 N · 样本范围。
- 标注员多选下拉（可搜索；仅显示已审核通过且已授权该项目的标注员；无可用时提示先到用户管理完成项目授权）。
- 可选截止时间；**取消**/**确认指派**（未选人禁用）；服务端返回重叠警告时弹窗保持打开并显示警告。

### 2.5.6 批注管理弹窗
- 筛选：批注状态（全部/待处理/已解决）、样本 ID 搜索、批注线程（全部/仅主批注/仅回复）、**刷新**、计数。
- 列表每项：样本/任务标识、状态标签、内容；操作**标记已解决**/**重新打开**；**加载更多**。

### 2.5.7 手工标注工作台（旧版任务）
- 顶栏：**返回任务列表**、**导出标注**（CSV/XLSX 下拉）、**保存到数据管理**（任务完成后可用，保存为新数据集并跳数据管理）、**刷新**。
- **样本队列**：样本数与进度标签；全部样本按钮列表（显示 ID、行号、当前标签[按告警级别着色]），点击选择。
- **样本详情**：
  - **人工标签编辑器**：状态提示（保存中/已选并自动保存/未标注）、**编辑/完成**切换标签管理态、标签选项按钮组（点击即保存并覆盖当前样本）、编辑态删除标签、新建标签输入（回车/添加按钮，按类型归一化校验）。
  - **当前样本数据**：全部真实字段键值展示。
- 任务运行中每秒自动刷新。

## 2.6 自动建模（AutoML）

### 2.6.1 任务列表页
- 标题 + **新建**按钮；建模任务表格 + **刷新**链接；存在排队/运行中任务时每 1.5 秒轮询。
- 表格列：项目、创建人、实验（名称+类型标签[点焊建模/自动建模]）、状态、建模进度（x/y 百分比）、错误详情、操作。
- 行操作：**查看建模结果**（进详情页）、**停止建模任务**（pending/queued/running）、**删除建模任务**（仅终态，二次确认）。

### 2.6.2 新建通用自动建模弹窗
字段：项目、数据集、实验（已被 AutoML 使用的实验禁选，附**新建实验**链接：名称+描述）、目标列（多输出任务多选）、输入列（仅数值列，默认全选）、任务类型（分类/多输出分类/回归/多输出回归）、算法家族（LightGBM/XGBoost/CatBoost/GBDT/随机森林/极端随机树/HistGradientBoosting，默认全选）、搜索方法（网格/随机/贝叶斯优化[默认]/进化/多保真）、搜索强度（10/30/80/200 次）、总时间上限（30/60/120/240 分钟）、类别权重开关（分类）、交叉验证开关与折数（2-5）。
**运行**按钮：带幂等键提交，成功后跳转任务详情页。

### 2.6.3 任务详情页
每 2 秒轮询。构成：

## 1. 评审任务列表

  - **批注**：进入评审工作区逐条浏览并批注。
  - **未回传任务**：以上三按钮全部禁用，tooltip 提示"任务未回传，不能验收/退回/批注"。
- 操作成功显示结果消息（如"已验收「任务名」，生成数据版本 vN"）。
- **分页**：上一页 / 共 N 条 / 下一页（游标分页）；加载/错误/空态与**重试**。

## 2. 评审工作区
- 头部：**← 返回任务列表**、任务标题、样本位置（第 N / 总数）。
- **样本浏览导航**：**上一条** / 当前样本 ID（等宽字体）/ **下一条**（触底自动加载下一页并预取；←/→ 键盘导航）。
- **样本数据**：多列卡片网格展示样本全部可见字段（字段名+值，空值显示"未标注"）。
- **标注结果（只读）**：按标签方案逐列展示标注值，不可编辑。
- **批注区**：
  - 当前样本批注列表（作者、时间、内容）。
  - 批注输入框（≤4000 字；**停止输入 800ms 后自动保存**，Ctrl+Enter 立即提交；切换样本前自动落盘）。
  - **添加批注**按钮；保存状态提示（保存中/已保存/停止输入后自动保存）。
  - 未回传任务：输入框禁用并提示"任务未回传，无法批注"。
- 任务不存在（已删除/归档）时显示兜底提示 + 返回按钮。

## 3. 与主平台的联动
- 主平台「数据标注 → 回传验收面板」的**在标注员门户查看明细**按钮即可深链接打开本门户评审工作区。
- 管理员在本门户**验收通过**后，平台生成新数据版本、任务转已完成；**退回**后任务回到标注员侧重新编辑（标注员任务队列显示"需重做"徽标与质检反馈条）。
