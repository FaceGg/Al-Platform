# 用户手册 — 汽车焊接制造工艺智能体编排平台

## 快速开始

### 1. 环境要求

- Python 3.9+
- Node.js 18+
- npm 9+

### 2. 启动后端

```bash
cd ml-platform/backend
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

后端启动后访问：
- API文档：http://localhost:8000/docs
- 健康检查：http://localhost:8000/api/health

### 3. 启动前端

```bash
cd ml-platform/frontend
npm install
npm run dev
```

### 4. 登录系统

打开浏览器访问 http://localhost:5173

默认账号：
- 用户名：`admin`
- 密码：`admin123`

## 功能指南

### 项目管理

项目管理是平台的顶层组织单元，每个项目包含工作流、数据集、模型等资源。

**创建项目**：
1. 进入首页，点击「新建项目」
2. 填写项目名称和描述
3. 点击创建

**项目详情**：
- 左侧导航：工作流列表
- 右侧区域：项目概览（数据集数、模型数、工作流数）

---

### 工作流编辑

工作流是平台的核心，通过拖拽算子构建ML处理流水线。

**基本操作**：
1. 进入项目 → 点击「新建工作流」
2. 从左侧算子库拖拽算子到画布
3. 连接算子端口建立数据流
4. 点击算子可配置参数
5. 点击「运行」执行工作流

**常用算子搭配示例**：

| 场景 | 算子链路 |
|------|----------|
| 数据预处理 | CSV导入 → 缺失值处理 → 标准化 → 数据分割 |
| 分类训练 | CSV导入 → 缺失值处理 → 标准化 → 随机森林 → 分类评估 |
| 回归预测 | CSV导入 → 标准化 → XGBoost → 回归评估 |

**工作流执行**：
- 绿色：执行中
- 蓝色：等待执行
- 红色：执行失败（点击查看错误日志）
- 灰色：执行完成

**实时监控**：
- WebSocket连接自动推送节点执行状态
- 运行日志面板实时更新

### 焊接质量预测模板

平台为焊接场景预置了工艺模板，一键创建工作流。

**使用模板**：
1. 进入项目 → 点击「模板」
2. 选择「焊接质量预测」模板
3. 系统自动创建标准工作流：数据导入 → 预处理 → XGBoost训练 → 评估

**数据格式要求**：

| 列名 | 类型 | 说明 | 示例 |
|------|------|------|------|
| current | float | 焊接电流(A) | 8500 |
| voltage | float | 焊接电压(V) | 6.2 |
| pressure | float | 电极压力(N) | 3200 |
| time | float | 通电时间(ms) | 200 |
| quality | int | 焊点质量(0/1) | 1 |

### 知识库与RAG问答

知识库用于管理和检索焊接工艺知识。

**上传文档**：
1. 进入「知识库」页面 → 创建知识库
2. 点击「上传文档」，支持格式：`.txt`、`.md`、`.csv`
3. 上传后系统自动分块存储

**向量化**：
1. 在知识库详情页点击「向量化」
2. 系统使用TF-IDF对全部文档进行嵌入
3. 嵌入结果同步写入VectorStore供快速检索

**搜索**：
- **标准搜索**：输入关键词，系统基于TF-IDF向量相似度返回相关段落（中文经jieba分词，检索粒度更准）
- **混合搜索** (`/search/hybrid`)：支持元数据过滤 + 关键词加权
  - `metadata_filter`：按文档ID等条件过滤，如 `{"doc_id": "xxx"}`
  - `keyword`：关键词在内容中出现则加权，否则降权（0.3系数）
- **重嵌入** (`POST /bases/{kb_id}/reembed`)：切换分词器后对全部chunk重算向量；升级到jieba分词后，旧知识库执行一次即可恢复中文检索质量

**RAG问答**：
1. 在知识库中输入问题
2. 系统检索相关文档段落
3. 拼接上下文发送给LLM生成答案
4. 答案附带引用来源

**知识图谱**：
- 实体管理：创建工艺概念、材料、参数等实体节点
- 关系管理：定义实体间的语义关系
- 图谱可视化：展示完整的知识关联网络
- **自动抽取**：图谱页选择知识库后点击「自动抽取」，系统按规则+统计（jieba名词短语、同句共现、「是一种/组成」模式）从文档自动生成实体与关系；自动层可反复重建，手动创建的实体/关系永不覆盖；实体列表带「自动/手动」徽标

### AI对话（绑定知识库 / 发布为API）

「AI 对话」页除直接与 LLM 对话外，还支持：

1. **绑定知识库（RAG）**：设置弹窗选择「知识库（RAG）」→ 保存。之后每条提问先在所选知识库检索相关段落（默认 top 4），回答基于检索内容并标注 `[n]` 引用序号，消息下方「引用来源」可展开查看命中的文件与相似度；未命中时按通用助手回答并提示。选择持久化在浏览器本地。
2. **发布为 API（远程调用）**：绑定知识库后点击「发布为 API」→ 在「API 市场」生成一条 Chat API（绿色徽标，`source_kind=chat`）。远程调用端点：

```
POST /api/platform/apis/chat/{知识库ID}/invoke
Authorization: Bearer <平台token>
{"message": "点焊飞溅的原因？", "top_k": 5, "system_prompt": "...", "temperature": 0.3}
```

返回 `{"reply", "sources", "kb", "usage"}`。错误语义：404 未知/无权限、409 已下线、422 参数非法、503 服务端未配置 `LLM_API_KEY`、502 LLM 调用失败。**凭据仅来自服务端配置**，调用方不能传 `api_key`/`model`；调用计入市场调用/成功/失败统计；知识库删除时其 Chat API 自动下线；重新发布幂等；市场可直接删除（模型 API 除外）。

### 自动化建模 (AutoML)

一键完成从数据到模型的全流程。

**操作流程**：
1. 确保项目中有数据集
2. 进入「AutoML」页面
3. 选择目标列（如：quality）
4. 选择任务类型（分类/回归）
5. 点击「开始建模」
6. 系统自动执行：
   - 特征工程（缺失值填充、编码、标准化）
   - 多模型对比训练（RF/XGBoost/LogisticRegression）
   - 5-fold交叉验证评分
   - 推荐最优模型

**查看结果**：
- 对比各模型的准确率/F1/ROC-AUC
- 下载最优模型
- 查看特征重要性排名

### 闭环演示（推理-回流-告警-审核-重训-换模型）

从左侧导航进入「闭环演示」，页面地址为 `/demo-loop`。它把推理部署串成一条可在线演示的自动化闭环：

1. **配置**：选择项目、推理部署，填写报错类别（预测命中即回流）、告警阈值（每 N 行报错触发一次告警，1 表示逐条触发）、是否人工审核及审核标注员，以及自动重训（触发行数、重训数据集、目标列、试验次数）。逐行预测优先走推理部署的运行时（与正式推理完全一致）；「自动特征工程」开关开启后，上传的原始点焊报告行（报告字段 + cvei/cvev/cver/cvep 四条波形列）会先经平台特征工程算子补齐派生列与波形统计列再做预测，未开启时要求上传的数据已包含模型的全部特征列。
2. **数据回放**：上传 CSV 后逐行调用推理（服务端加载部署当前模型制品做单行预测），页面逐行展示预测类别、置信度和是否回流，并带进度条与动效。
3. **数据回流**：命中的报错行自动写入项目的报错数据集制品（在「数据管理」中可见，持续追加）。
4. **阈值告警**：报错行数达到阈值时给项目所有者与平台管理员发送站内通知（右上角通知中心），并在事件流中记录。
5. **人工审核**：开启后，告警会自动创建通用标注任务（绑定报错数据集版本与分类标签 schema）并分配所选标注员，可在「数据标注」跟进。
6. **自动重训与换模型**：报错积累达到重训行数时自动创建 AutoML 任务（light 档强度、贝叶斯搜索）；任务完成后自动注册最优候选为模型版本并批准，替换推理部署的模型，事件流记录替换前后版本。

「重置闭环」清空回流行数、告警计数与事件（保留配置与报错数据文件）。接口为 `/api/projects/{project_id}/demo-loop/...`（config/predict/status/reset）。

另有一个**独立大屏动画演示页**：`http://<前端地址>/demo-showcase.html`（如 `http://localhost:5173/demo-showcase.html`，无需登录）。以节点图 + 数据流动粒子动画完整演绎"上传 → 逐行调用 → 特征工程 → 推理 → 分类判断 → 正常继续 / 报错回流 → 报错数据集 → 阈值监测 → 告警通知 → 人工审核 → 自动建模 → 模型替换 → 回到推理"的闭环。12 个节点各有专属造型与动效：终端窗口（逐行调用，循环打字）、旋转齿轮 + 73F 徽标（特征工程）、带引脚的 CPU 芯片（模型推理）、六边形判断体带绿/红决策灯（分类判断）、数据库圆柱 + 数字计数与堆叠条（报错数据集）、随积累填充的仪表盘（阈值监测）、触发时摆动的铃铛 + 告警计数徽标（告警通知）、清单对勾描画（人工审核）、双卫星轨道（自动建模）、金色循环换箭（模型替换）等；**自动建模前有圆形「重训阈值」判断节点**（进度环显示 `已积累 / 阈值`，未达标的数据沿虚线弹回报错数据集继续积累，达标才放行触发建模，换模型后进入下一轮阈值周期）；带 HUD 计数与自动换模型动效；支持播放/暂停/重置/倍速。

**连接真实数据**：左下角切到「模式：实时」，项目下拉框自动加载当前登录用户可见的项目（Token 自动读取本浏览器主界面登录态，也可手动粘贴），点「连接」后每 2 秒轮询真实闭环状态：报错数据集行数、告警次数、重训阈值环均显示真实数值，新产生的预测/回流/告警/重训/换模型事件会实时驱动对应节点动画。注意：事件流展示最近 50 条内的动画回放；页面内不能直接登录（平台 CSRF 策略），请先在主界面登录同一浏览器。闭环演示页顶部有「大屏动画演示」按钮直达。

### 编排 API（方案B：工作流发布为服务）

工作流画布顶部新增**「发布为 API」**按钮：把当前草稿发布为版本并注册为编排 API（`source_kind=orchestration`），出现在「API 市场」（类型 Orch. API，紫色徽标，可筛选）。

**服务图约定**：可发布的图必须包含 `api_input`（接收逐行调用输入）和 `apply_model`（推理）节点，且**不得包含训练/搜索算子**——模型用新的 **`load_model_artifact` 算子**绑定已训练的模型制品（参数填模型制品 ID，支持模型库/AutoML 的打包结构，自动解包出估计器）。典型服务图：`api_input → apply_model（模型口接 load_model_artifact）→ condition`。这样训练/服务阶段天然分离：训练留在训练工作流里，服务图每次调用只做推理。

**调用**：编排 API 的调用端点为 `POST /api/platform/apis/orchestration/{版本ID}/invoke`，请求体 `{"record": {...单行特征...}}`，返回 `{"records": [...预测后数据...], "branch": "true|false", ...}`——branch 是记录命中的条件分支，records 来自该分支。调用会累计 API 市场的调用/成功计数；工作流删除时其编排 API 自动下线；「发布为 API」重复点击幂等（同一版本同一 API）。发布后再次点击可重新上线；下线用市场页或 `.../offline` 端点（相当于暂停，可恢复）。

**删除**：API 市场每行的 Actions 提供「删除」（红色图标，确认弹窗）。删除规则按来源区分：自定义 API 和编排 API 可直接删除（编排 API 删除后重新「发布为 API」会按同版本幂等重建）；**模型 API 不可在市场删除**——它由推理部署的生命周期管理（删除按钮不显示），请在模型库对部署做下线/删除。删除后市场计数与统计立即更新。

### 数据标注

**基于规则标注**：
- 定义标注规则（如：quality=1 if current>8000 and voltage>5.5）
- 系统自动对数据集执行规则标注

**基于相似度标注**：
- 提供少量已标注样本
- 系统计算未标注数据与样本的相似度
- 推荐高置信度标注供人工确认

### 通用数据版本与标注任务

通用平台面向扁平结构化数据。先在项目中导入 CSV、Excel、Parquet、JSON 或 XML，确认解析选项和列类型，再冻结数据版本。冻结后，原始文件、归一化表、schema hash、样本 ID 和输入合同都会保留，后续任务只能引用该不可变版本。

创建任务时选择数据版本和多列标签 schema。手动任务进入标注员指派流程；自动任务选择项目内模型制品、搜索强度和自动标注策略。任务列表是操作中心，预览、执行、暂停、恢复、回传、验收和归档都在当前任务上下文中完成，不会自动跳转到行业专用详情页。

预览完成后先检查样本范围、可见列、标签 schema、模型输出、策略来源和需要复核的数量，再执行任务。只有当前配置 revision 的预览完成后，执行按钮才可用。刷新页面或切换项目不会复用旧项目的数据版本、模型制品或预览。

### 独立标注员门户

门户地址和端口由部署配置提供，默认端口为 `8443`。标注员使用独立账号注册和登录，只能看到服务端授权的任务和样本，浏览器提交的项目、标注员和范围参数不会覆盖服务端授权。

在工作区中按标签列类型填写整数、浮点数、字符串、枚举或自由文本。自动保存携带样本 revision；若其他标注员先提交，页面会显示版本冲突和服务端完整标签集合，必须确认完整集合后才能覆盖。批量标注会先显示受影响样本数，并要求显式确认。

确认全部样本后执行回传。成功回传的范围会锁定为只读；需要修改时先点击“编辑回传”，完成新修订后才可再次回传。管理员可在数据管理页面查看差异、验收或填写原因退回；验收会从原始不可变版本生成新的数据版本，原版本不会被覆盖。

### 模型注册、导出与离线运行

AutoML 完成后，候选只作为制品保留。管理员从完整候选中手动注册模型并经过批准后，模型库才显示预测和标注导出操作。导出任务完成前只能查看状态，只有校验和、SBOM 和签名验证通过的 `ready` 包可以一次性下载。

离线 `predict` 或 `annotate` 运行前需要提供与导出包匹配的输入合同。缺列、类型不符、非法枚举、超范围、无效样本 ID 或非有限数值都会拒绝整批输入，不会生成可误用的部分结果。

## 常用问题 (FAQ)

**Q：上传大文件失败？**
A：默认上传限制10MB，可在 `config.py` 中调整 `MAX_UPLOAD_SIZE`。

**Q：工作流执行报错？**
A：查看运行日志面板，常见原因：数据格式不匹配、缺少必需参数、算子间端口类型不一致。

**Q：向量搜索返回空？**
A：确保已执行「向量化」操作。检查知识库中是否有已嵌入的文档。

**Q：如何切换数据库？**
A：修改 `config.py` 中的 `DATABASE_URL`，支持SQLite和PostgreSQL。生产环境建议使用PostgreSQL。

**Q：如何添加自定义算子？**
A：参考 `backend/app/operators/` 目录下现有算子，继承 `BaseOperator` 并使用 `@register_operator` 装饰器注册。
