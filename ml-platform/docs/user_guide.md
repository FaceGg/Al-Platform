# 用户手册 — 汽车焊接制造工艺智能体编排平台

## 快速开始

### 1. 环境要求

- Python 3.9+
- Node.js 18+
- npm 9+

### 2. 启动后端

```bash
cd ml-platform/backend
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

后端启动后访问：
- API文档：http://localhost:8000/docs
- 健康检查：http://localhost:8000/api/health

### 3. 启动前端

```bash
cd ml-platform/frontend
npm install
npm run dev
```

### 4. 登录系统

打开浏览器访问 http://localhost:5173

默认账号：
- 用户名：`admin`
- 密码：`admin123`

## 功能指南

### 项目管理

项目管理是平台的顶层组织单元，每个项目包含工作流、数据集、模型等资源。

**创建项目**：
1. 进入首页，点击「新建项目」
2. 填写项目名称和描述
3. 点击创建

**项目详情**：
- 左侧导航：工作流列表
- 右侧区域：项目概览（数据集数、模型数、工作流数）

---

### 工作流编辑

工作流是平台的核心，通过拖拽算子构建ML处理流水线。

**基本操作**：
1. 进入项目 → 点击「新建工作流」
2. 从左侧算子库拖拽算子到画布
3. 连接算子端口建立数据流
4. 点击算子可配置参数
5. 点击「运行」执行工作流

**常用算子搭配示例**：

| 场景 | 算子链路 |
|------|----------|
| 数据预处理 | CSV导入 → 缺失值处理 → 标准化 → 数据分割 |
| 分类训练 | CSV导入 → 缺失值处理 → 标准化 → 随机森林 → 分类评估 |
| 回归预测 | CSV导入 → 标准化 → XGBoost → 回归评估 |

**工作流执行**：
- 绿色：执行中
- 蓝色：等待执行
- 红色：执行失败（点击查看错误日志）
- 灰色：执行完成

**实时监控**：
- WebSocket连接自动推送节点执行状态
- 运行日志面板实时更新

---

### 焊接质量预测模板

平台为焊接场景预置了工艺模板，一键创建工作流。

**使用模板**：
1. 进入项目 → 点击「模板」
2. 选择「焊接质量预测」模板
3. 系统自动创建标准工作流：数据导入 → 预处理 → XGBoost训练 → 评估

**数据格式要求**：

| 列名 | 类型 | 说明 | 示例 |
|------|------|------|------|
| current | float | 焊接电流(A) | 8500 |
| voltage | float | 焊接电压(V) | 6.2 |
| pressure | float | 电极压力(N) | 3200 |
| time | float | 通电时间(ms) | 200 |
| quality | int | 焊点质量(0/1) | 1 |

---

### 知识库与RAG问答

知识库用于管理和检索焊接工艺知识。

**上传文档**：
1. 进入「知识库」页面 → 创建知识库
2. 点击「上传文档」，支持格式：`.txt`、`.md`、`.csv`
3. 上传后系统自动分块存储

**向量化**：
1. 在知识库详情页点击「向量化」
2. 系统使用TF-IDF对全部文档进行嵌入
3. 嵌入结果同步写入VectorStore供快速检索

**搜索**：
- **标准搜索**：输入关键词，系统基于TF-IDF向量相似度返回相关段落
- **混合搜索** (`/search/hybrid`)：支持元数据过滤 + 关键词加权
  - `metadata_filter`：按文档ID等条件过滤，如 `{"doc_id": "xxx"}`
  - `keyword`：关键词在内容中出现则加权，否则降权（0.3系数）

**RAG问答**：
1. 在知识库中输入问题
2. 系统检索相关文档段落
3. 拼接上下文发送给LLM生成答案
4. 答案附带引用来源

**知识图谱**：
- 实体管理：创建工艺概念、材料、参数等实体节点
- 关系管理：定义实体间的语义关系
- 图谱可视化：展示完整的知识关联网络

---

### 自动化建模 (AutoML)

一键完成从数据到模型的全流程。

**操作流程**：
1. 确保项目中有数据集
2. 进入「AutoML」页面
3. 选择目标列（如：quality）
4. 选择任务类型（分类/回归）
5. 点击「开始建模」
6. 系统自动执行：
   - 特征工程（缺失值填充、编码、标准化）
   - 多模型对比训练（RF/XGBoost/LogisticRegression）
   - 5-fold交叉验证评分
   - 推荐最优模型

**查看结果**：
- 对比各模型的准确率/F1/ROC-AUC
- 下载最优模型
- 查看特征重要性排名

---

### 模型训练管理

**手动训练**：
1. 在项目工作流中选择训练算子
2. 配置超参数（如RF的n_estimators、XGBoost的max_depth）
3. 运行工作流
4. 训练完成后模型自动保存到模型库

**训练监控**：
- 实时loss/accuracy曲线（WebSocket推送）
- 早停提示
- 检查点保存

**模型版本**：
- 每次训练自动生成新版本（v1, v2, ...）
- 可在模型库中查看和管理历史版本

---

### 资源监控

进入「监控」页面查看系统资源：

- **CPU**：使用率百分比
- **内存**：已用/总量
- **磁盘**：剩余空间
- **GPU**：显存使用率（如可用）

历史数据支持时间范围筛选。

---

### 多智能体协同

面向复杂焊接工艺问题，启用多智能体协同处理。

**配置智能体**：
1. 在协同管理页面注册智能体
2. 设置智能体类型：planner（规划）、executor（执行）、reviewer（审核）
3. 配置智能体能力描述

**任务协同**：
1. 创建任务，描述需求
2. LLM Planner自动分解为子任务
3. 系统根据能力匹配分配Executor
4. Reviewer审核执行结果
5. 最终聚合输出

### API 市场

从左侧导航进入「API 市场」，页面地址为 `/api-marketplace`。不要直接访问后端根路径 `/api-marketplace`，该路径由前端路由提供。

API 列表和工作台统计均来自后端 `PlatformAPI` 权限过滤查询，不使用页面本地数组推算。新建 API 当前仅支持自定义 API，路径必须是平台内部的 `/api/...` 地址；模型 API 在推理部署成功启动后自动生成，重复启动不会产生重复记录，停止部署会将对应 API 标记为下线。

API 测试器只允许测试目录中的同源内部 endpoint，并通过当前登录会话发送 Bearer Token；不支持将任意外部 URL 作为代理目标。

---

### 数据标注

**基于规则标注**：
- 定义标注规则（如：quality=1 if current>8000 and voltage>5.5）
- 系统自动对数据集执行规则标注

**基于相似度标注**：
- 提供少量已标注样本
- 系统计算未标注数据与样本的相似度
- 推荐高置信度标注供人工确认

## 常用问题 (FAQ)

**Q：上传大文件失败？**
A：默认上传限制10MB，可在 `config.py` 中调整 `MAX_UPLOAD_SIZE`。

**Q：工作流执行报错？**
A：查看运行日志面板，常见原因：数据格式不匹配、缺少必需参数、算子间端口类型不一致。

**Q：向量搜索返回空？**
A：确保已执行「向量化」操作。检查知识库中是否有已嵌入的文档。

**Q：如何切换数据库？**
A：修改 `config.py` 中的 `DATABASE_URL`，支持SQLite和PostgreSQL。生产环境建议使用PostgreSQL。

**Q：如何添加自定义算子？**
A：参考 `backend/app/operators/` 目录下现有算子，继承 `BaseOperator` 并使用 `@register_operator` 装饰器注册。
