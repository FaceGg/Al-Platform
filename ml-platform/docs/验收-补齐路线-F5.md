## 3. 未验证与遗留

- **not_run**：Kafka 真实链路（本机无 Kafka）；`docker compose config`（本机无 docker，CI 背书）；页脚条真实浏览器渲染；Kafka 消费循环长跑稳定性。
- **登记遗留**：API 市场页的「项目开放密钥」管理界面未做（后端管理端点已齐，可经 API 使用）；kafka-ingest 的事件归属当前取首个项目（真实多项目路由随接入场景建设）。
- **实施修复（测试拦下）**：①项目级 Key 的 scope 校验器不认 project.read（ALLOWED_SCOPES 扩展）；②幂等哈希误含 occurred_at（重放时间戳漂移导致同 ID 误判内容不一致——哈希只算业务内容）；③duplicate 状态不得插行（原 ID 占用唯一键，幂等语义=跳过）；④同 ID 不同内容的追查行用派生 ID（`#replay-<hash8>`）避免顶替原行。
- **安全扫描**：提交时扫描器多次未给出完整结论（scanner_enobufs），不据此宣称项目安全。
