## 4. 未验证与遗留

- **not_run（浏览器）**：曲线叠加、处置抽屉、下拉与批量确认等未在真实浏览器里验收——前端用例运行在 jsdom，图表为替身组件；只验证了渲染结构、调用载荷与交互逻辑。
- **not_run（调度）**：Celery beat 的真实巡检节奏（设备 5 分钟、SLA 10 分钟一轮）未在运行栈验证，只验证了两个任务体。
- **not_run（数据库）**：PostgreSQL 上 `_109` 的往返与外键 DDL 未在本地执行（本地仅 SQLite），由 CI 生产集成作业背书。
- **not_run（对象存储）**：MinIO 下的证据包下载与模型校验和重算未验证（本地走文件存储）。
- **not_run（门户）**：误报复核任务在标注员门户内的指派与标注操作未在浏览器验证；任务已建成待指派状态。
- **environment-blocked**：SLA 通知经钉钉 / 短信 / 邮件通道的真实送达需现场通道凭据，未执行；站内信通道已实测送达。
- **设计限界（如实登记）**：
  - 证据总览的「切分 / 主动选样 / 现场验证」三个环节标为未接入——第二批、第四批按用户 2026-11-26 指示暂停或门控，接入前保持该状态；下钻只到页面级，未定位到具体记录行。
  - 参数超限判定目前只评数值特征（规格统计量为「值」）；波形统计量规格待接入通道保存波形原文后生效。
  - 设备心跳恢复不自动关闭预警（按设计，人工确认后关闭）。
- **安全扫描**：提交时安全扫描器多次未给出完整结论（`scanner_enobufs`），本验收不据此宣称项目安全。
