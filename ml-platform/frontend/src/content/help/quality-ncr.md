# NCR-CAPA（质量管理 · 质量体系）

不合格与纠正措施的登记与关闭门禁（IATF 16949 口径，待质量专家评审）。

## 五阶段推进

draft → analysis → action → verification → closed，顺序推进、跳步被拒。

- **早期驳回**：draft / analysis 阶段可驳回，理由必填；驳回为终态；
- **关闭门禁（时间窗）**：进入 verification 后须连续 **21 天**（3 个验证周期 × 7 天）同场景 + 同工位无新预警方可关闭——判定只读时间与预警，反复点击不能"攒次数"；
- **复发判定**：验证期内（起点之后）同场景 + 同工位出现新预警即视为复发，关闭被拒；
- **周期计数**：每次被拦的尝试会在轨迹里留下"验证期 x/21 天"记录（随回滚撤销，以最终状态为准）。

## 登记来源

- 本页手工登记（编号 + 标题，可选来源预警 ID）；
- 关闭 critical 预警（确认为真实异常）时**自动开立质量案例**并关联来源预警——案例中心可查。
