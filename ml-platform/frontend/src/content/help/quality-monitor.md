# 实时生产监控（质量管理 · 监控）

实时生产监控是给现场用的：左侧产线 / 工位 / 设备三级树，右侧工位卡；新事件经推送流自动上屏。

## 工位卡

每张卡显示一个工位的当前状态：产品、批次、最新生产时间、最新结果（正常 / 异常 / 预测类别）、风险分数、本班次产量与异常数、未关闭事件数与最新一条预警、设备在线状态。

- **班次**默认按 早班 08–16 / 中班 16–24 / 夜班 00–08 划分，班次产量读当前班次内的小时聚合桶；
- **设备状态**来自设备台账的心跳：心跳超过时限未更新即显示「设备离线」——与设备巡检同一口径，不从推理记录反推；
- 三级树取自工位的产线归属与设备台账；点产线只看该产线，点工位只看该工位。

## 实时刷新

打开「自动刷新」后，页面优先使用推送流：与服务端建立长连接，有新事件时约 2 秒内上屏。连接建立失败或中途断开时，页面自动改为每 3 秒轮询一次，右上角会如实显示当前是「实时推送」「轮询」还是「已暂停」。

## 确认收到

班组长到场后点「确认收到」：该工位全部未关闭的预警会被一并确认，责任人记为当前用户，每条预警的轨迹里都会留下这条记录。没有未关闭预警时按钮不可用。

## 呼叫质量人员

需要质量工程师到场时点「呼叫质量人员」并填写原因（必填）。系统会通知该工位的责任人与项目负责人（站内信），并把这次呼叫记入审计日志。

## 数据可能已过期

与驾驶舱同一判定：范围内距最后一次有产量超过 24 小时会挂横幅。演示数据不计入。

> 权限：查看 = 项目成员；确认收到、呼叫质量人员 = 项目负责人、编辑者、操作员（班组长）。
