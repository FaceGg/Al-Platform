# 工位与设备（质量管理 · 配置）

工位是场景下的实体，代表一个物理工位；设备复用平台的边缘设备台账（不另建设备表）。工厂/车间/产线是工位上的归属字段（非实体），供后续批次驾驶舱的「工厂 → 车间 → 产线 → 工位」四级联动消费。

## 新建工位

1. 顶部选择项目与场景（首次使用先到「场景管理」建场景）。
2. 点击「新建工位」，填写编码（场景内唯一）、名称与归属字段。
3. **绑定边缘设备**：下拉只列出可绑定设备（设备属于当前用户才可绑定；跨成员设备共享随治理批次收敛）。

## 边缘设备

点「注册设备」弹出内嵌注册表单（名称/类型/IP），复用平台既有设备接口。设备绑定后，列表显示：

- **在线/离线**：按心跳判断，超过 180 秒无心跳即离线；
- **影子状态**：设备影子（desired/reported 双状态）为边缘批次（B4-02）预留字段，当前显示「未启用」。

## 责任人（预留）

工位责任人字段已建（`responsible_user_id`），确认防呆与预授权逻辑随预警处置批次接入；本页暂不展示该列。

> 权限：读 = 项目成员；写 = 项目 owner 或 editor（`quality.manage`）。
