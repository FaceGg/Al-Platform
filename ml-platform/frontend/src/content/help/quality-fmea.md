# FMEA（质量管理 · 质量体系）

失效模式与影响分析：失效模式 / 影响 / S·O·D 评分 / 预防措施。

## RPN 服务端计算

- S（严重度）、O（发生度）、D（探测度）各 1–10，**服务端 clamp**（超界截断）；
- **RPN = S×O×D 由服务端计算**——前端传入的 RPN 被忽略（防篡改）；
- RPN ≥ 100 视为高风险项（页面红/橙/绿着色）。

## 同步到控制计划

「同步控制计划」把 **RPN ≥ 100 项的预防措施**作为 recipe_change 审批单发起——批准后预防措施写入控制计划质量点并记决策流水（未批准前不生效）。同计划已有待批单时先到审批中心处理。
