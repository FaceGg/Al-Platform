# 批次追溯（质量管理 · 质量体系）

把**原始数据 → 模型判定 → 预警 → NCR** 四个对象按样本键串成链，按批次键聚合概览。

## 追溯链的登记

追溯链在业务动作发生时自动登记：

- 预警产生时（携带样本键 / 批次的真实预警；演示预警不进追溯）；
- NCR 从预警转入时（补 NCR 关联）；
- 批次概览与样本追溯按这些链聚合。

## 两个查询

- **样本追溯**：输入业务样本键（如 VIN），返回数据集版本、模型判定（按通道）、预警、关联 NCR；
- **批次概览**：输入批次号，返回样本数、推理明细、预警与 NCR 聚合。

无批次键的数据集在接入时就会被字段角色把关拦下（B1-10），因此追溯要求从源头满足。
