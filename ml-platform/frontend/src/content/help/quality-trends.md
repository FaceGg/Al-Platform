# 趋势与帕累托（质量管理 · 分析）

趋势页回答「质量在变好还是变坏、问题集中在哪」：NG 率走势、超限统计与缺陷帕累托。

## 时间窗与对比维度

- 时间窗：近 7 / 30 / 90 天；
- 对比维度：缺陷、工位、设备、产品、批次。切换维度只改预警表的分组方式，**不扫描推理明细**，大数据量下也是秒开；
- 顶栏同样支持四级范围与场景筛选。

## 走势图

- 柱：每日预警数、SPC 超限数（参数超限与 SPC 判异两类预警）；
- 线：NG 率 = 已确认 NG ÷ 当日产量。

## 帕累托图

按所选维度对时间窗内的预警分组，高度是发生次数，折线是累计占比——用来找「哪少数几类问题造成了大多数异常」。

- **按缺陷**时，预警的预测标签会经 **NG 词表**归并成缺陷类别；
- 没有预测标签的预警（如无监督模型）归入「未标注预测标签」单列；
- 没有上报产品或批次的预警归入「未上报产品 / 批次」。

## NG 词表

「预测标签 → 缺陷类别」的映射，例如 `spatter → 飞溅`。这份词表与质量报告共用同一份配置，只在一处维护。项目负责人与编辑者可以增改条目并保存。

## 导出 / 打印

「导出 / 打印」调用浏览器的打印功能，可另存为 PDF。

## 口径说明

NG 率按自然日计；已确认 NG 按预警的发生次数计；产量读小时聚合桶；演示数据不计入。与驾驶舱使用同一个聚合口径，同范围同时间窗下两页的数字一致。

> 权限：查看 = 项目成员；维护 NG 词表 = 项目负责人、编辑者。
