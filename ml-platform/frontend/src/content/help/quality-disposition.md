# 处置工作台（质量管理 · 监控）

处置工作台对单条预警做五阶段流转：**待确认 → 已确认 → 处理中 → 待复核 → 已关闭**。在预警中心点「处置」进入，或在本页直接点开一条。

## 证据区

每条预警并列展示四项依据，便于核对后再下结论：

- **实测值**：参数超限给出字段、实测值与规格上下限；模型风险给出分数、分数口径与触发下限；
- **规格上下限**：读自场景的规格定义（全平台只有这一份来源）；
- **基线（冻结版本）**：读自该工位/工况的冻结 SPC 基线。没有冻结基线时明确提示，此时只有规格判据可用；
- **模型依据**：模型版本、触发依据（阈值或模型判异），或设备的最近心跳时间。

## 判据链

按固定优先级复算：**规格超限 → 3σ 超限 → 2σ 偏离 → 基线偏离 30%**。每条判据标注命中、通过或不适用。复算读的是**当前**规格与现行基线——修改规格后结果随之变化。

## 曲线叠加

预警的样本键能在场景波形列所在的就绪数据集版本里找到时，叠加显示波形与规格目标窗口。没有波形时页面会说明原因（未声明波形列、样本键不一致或编码不符）。

## 处置表单与留档

提交处置时填写：关闭结论（确认异常 / 误报 / 其他）、处置类型、原因、措施、停机 / 返工 / 扩大检查标记。确认为真实异常时原因与措施必填。

平台会把**当时生效的 SOP 版本、SPC 基线版本与模型版本**冻结进这张处置单。之后的 SOP 修订、基线重新冻结、模型更换都不会改写已提交的处置单——审厂时可以回答「当时依据的是什么」。

- **误报**：自动生成一条复核任务进入标注回流队列，可在数据标注页指派；
- **确认异常**：对应小时的「人工确认 NG」计数加一（供驾驶舱与趋势使用）。

## 附件与轨迹

处置照片或文件可直接上传。下方轨迹按时间完整记录每一次确认、流转、转交、复核、处置与 SLA 通知。
