# SPC 过程控制（质量管理 · 分析）

SPC（统计过程控制）用控制图判断「过程的波动是正常的，还是出了需要处置的事」。

## 数据来源

二选一：

- **数据集版本**：任选其中一个数值列，按行序取最新的至多 5,000 个点；
- **推理结果**：预测值、异常分数或预测概率，按时间窗取最新的至多 5,000 条（不含演示通道）。

## 控制图与判异

- 变量图：I-MR（单值）、X̄-R、X̄-S（子群，容量 2–10）；
- 计数图：P（不合格率）、NP、C、U——需要指定「是否缺陷」的布尔列（数据集来源）或用「异常」标记（推理来源），按子群统计；
- 判异按 **Nelson 规则 1–8**，命中点在图上标红，明细列出每一条（规则、点位、数值、样本键）。

## 规格限与能力指数

规格限**优先取场景的规格定义**（全平台同一份来源），也可以手工录入逐项覆盖，结果里会标明来源。有规格限才计算能力指数：Cp / Cpk 用组内标准差、Pp / Ppk 用整体标准差、另有 Cpm / Cr / σ 水平 / 估计 PPM。

**组内 σ 的三个来源**（页面会注明用的是哪个）：

1. 子群极差估计（按子群取数时）；
2. 冻结基线的 σ（在「SOP 维护 › SPC 基线」里冻结；按工位、工况回退匹配）；
3. 都没有时**回退整体标准差**——此时 Cp / Cpk 实际等同于 Pp / Ppk，**不代表过程能力**，页面会明确提示。

缺规格限时能力指数留空，不报错。

## 登记预警

打开「登记预警」开关后（需要处置权限），判异点会按「图 + 规则」折叠成 SPC 判异类预警进入预警中心，证据里带样本键与数值；窗口内重复分析同一批点只增加计数。越出**冻结基线控制限**的推理值也会实时产生这类预警，不需要手动分析。

## 口径说明

控制限取自标准常数表（A2·R̄ 等）；Cp / Cpk 与 Pp / Ppk 的 σ 口径不同，见上文；估计 PPM 按正态分布近似。分析只读数据，不改任何东西。

> 权限：分析 = 项目成员；登记预警 = 项目负责人、编辑者、操作员。
