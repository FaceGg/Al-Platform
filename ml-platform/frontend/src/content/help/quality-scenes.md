# 场景管理（质量管理 · 配置）

场景是「项目 → 场景 → 工位 → 设备」领域模型的第二层：一个场景代表一类工序质量业务（如点焊质量、拧紧质量），权限继承所属项目，一个场景对应一个推理部署（可先建后绑）。

## 新建场景

1. 顶部选择项目，点击「新建场景」。
2. 填写编码（项目内唯一，如 `welding-cell-a`）与名称；描述可选。
3. **工况列**：场景声明的路由键。绑定部署时必须与部署声明的工况列一致，否则保存被拒绝（422）。场景未声明工况列时允许直接绑定。
4. **波形列**（可选）：声明波形数据所在列，供后续批次的曲线叠加把关消费。

## 字段角色

字段角色把数据列映射为业务含义，训练时自动排除非特征列：

- **样本键**（sample_key）、**产品**、**批次**、**班次**、**采集时间**、**时间列**、**分组列**、**工况列**、**波形列**、**忽略列**——这些角色占用的列在「自动建模」绑定该场景时不进模型输入；
- **目标列**（target）是预测目标；**特征列**（feature）保留在输入中；
- 每个角色只能映射一列（一列不能同时承担两个角色）。

角色映射在「自动建模」页选择「质量场景」后生效：绑定场景的任务会把排除列随训练请求下发，由引擎在候选特征列上做差集。

## 规格定义

点开场景行的「规格」抽屉维护规格：**字段 + 统计量（值/均值/最小/最大/RMS）+ 上下限/目标值 + 单位**。同一字段与统计量只能有一条规格。规格定义是全平台单一来源——后续批次的判据引擎（超限判定）与 SPC 能力指数都从这里取数，不再各处单独配置。

## 删除

删除场景会级联删除其下的工位与规格定义（数据库外键级联），操作前请确认。

> 权限：读 = 项目成员；写（新建/编辑/删除/角色/规格）= 项目 owner 或 editor（`quality.manage`）。
