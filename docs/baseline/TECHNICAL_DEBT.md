## 清理原则

- 正式源码、迁移、测试与文档纳入版本控制。
- 数据库、日志、构建目录、缓存和 `tsbuildinfo` 作为生成物忽略。
- 上传文件和测试样本可能属于用户资产，未确认所有权前不删除。
- `_fix_*`、`append_*`、`test_write.txt` 等临时脚本先登记用途，再决定迁移到工具目录或删除。
