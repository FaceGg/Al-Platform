## 一、产品定位

### 1.1 产品愿景

搭建一套 **Web 版可视化机器学习工作流平台**，使业务/产线人员无需编程即可通过拖拽算子完成数据分析与建模，同时为算法工程师提供灵活的深层次定制能力。平台自带传统机器学习与深度学习方法，支持数据处理、可视化、模型训练、评估、测试与导出全流程。

### 1.2 目标用户

| 用户类型 | 使用方式 | 核心需求 |
|----------|----------|----------|
| **产线/业务人员** | 模板引导 + 拖拽配置 | 快速复用预设流程，一键运行，可视化结果，零代码 |
| **算法工程师** | 自由拖拽 + Python 脚本扩展 | 灵活构建任意 pipeline，调参，自定义算子，模型导出 |
| **系统管理员** | 项目管理、用户管理 | 权限控制、资源监控、版本管理 |

| 部署方式 | 桌面 | 桌面/Server | 桌面/Server | **Web 原生** |

## 四、双视角工作流设计

### 4.1 模板视图 (面向产线/业务用户)

模板本质是"预定义工作流 + 参数简化层"。


### 4.2 自由工作流视图 (面向算法工程师)

三栏式工作台布局:
1. 左侧: 算子面板(分类/搜索/拖拽到Canvas)
2. 中间: ReactFlow Canvas(拖拽节点/连接箭头/缩放)
3. 右侧: 上下文面板(参数编辑/数据预览)

关键交互:
- 从算子面板拖拽到 Canvas 创建节点
- 从输出端口拖拽到输入端口创建边
- 双击节点打开快速参数编辑
- 右键菜单: 复制/删除/禁用/注释
- 快捷键: Ctrl+S 保存, Ctrl+R 运行, Delete 删除
- 节点颜色: 灰=未运行, 蓝=运行中, 绿=成功, 红=失败

模板生命周期:
1. 预置模板: 系统初始化自动创建(焊接质量/视觉缺陷/时序预测)
2. 用户自定义模板: 算法工程师从自由工作流"另存为模板"
3. 模板共享: 同一项目下模板可被所有成员使用
4. 模板版本: 支持版本迭代, 旧工作流可用旧版本运行

## 五、工作流引擎设计

### 5.1 DAG 执行流程

1. 解析工作流 JSON -> NetworkX DiGraph
2. DAG 校验: 环检测, 端口连通性, 参数合规, 数据类型匹配
3. 拓扑排序
4. 任务调度: 同层独立节点并行, 依赖链按序
5. 长任务(>30s)提交到 Celery worker
6. WebSocket 推送节点状态到前端
7. 错误处理: 失败节点标记并跳过下游, 支持断点续跑

### 5.2 数据传递策略

| 数据大小 | 传递方式 | 典型场景 |
|---------|---------|---------|
| < 5MB | JSON 直接传递 | 小数据集/元数据 |
| 5MB-500MB | Parquet 文件 | 中等结构化数据 |
| > 500MB | Arrow IPC 分块读取 | 大数据集流式处理 |

## 六、数据模型设计

核心数据库表 (PostgreSQL):
- users: 用户表(username, password_hash, role)
- projects: 项目表(name, description, owner_id)
- workflows: 工作流表(project_id, name, type, is_template)
- nodes: 算子节点实例(workflow_id, operator_id, position, params JSONB)
- edges: 边连接(source_node, source_port, target_node, target_port)
- workflow_runs: 执行记录(status, started_at, error_message)
- node_runs: 节点执行快照(run_id, node_id, status, output_meta JSONB)
- artifacts: 数据集/模型文件记录(project_id, type, storage_path, format)

## 九、分阶段实施计划

### 第一阶段: MVP (约 8 周)

第1-2周: 工程基础设施
- FastAPI 项目骨架 + SQLAlchemy 模型
- React + ReactFlow + Ant Design 初始化
- 用户认证系统 (JWT)
- 项目/工作流 CRUD API

第3-4周: 核心工作流引擎
- DAG 调度器 (NetworkX)
- 算子基类和注册机制
- WebSocket 实时状态推送
- 基础数据传递机制

第5-6周: 前端拖拽工作流编辑器
- ReactFlow 自定义节点(输入/输出端口)
- 算子面板 + 搜索/分类
- 节点属性编辑面板
- 边的连接验证 + 执行状态显示

第7-8周: 首批算子 + 模板
- 10+ 核心算子(导入CSV/缺失值/编码/缩放/划分/LR/RF/XGBoost/评估/混淆矩阵)
- "焊接质量预测" 模板
- 结果预览面板

里程碑: 全链路可运行
[导入CSV] -> [缺失值] -> [编码] -> [缩放] -> [划分] -> [XGBoost] -> [评估]

### 第二阶段: 深度学习 + 完整算子 (约 8 周)

第9-10周: 深度学习算子
- MLP / CNN / LSTM 节点

第11-12周: 高级评估 + 可视化
- ROC/PR曲线, 学习曲线, 特征重要性
- 超参搜索, 交叉验证

第13-14周: 模型导出 + Python 脚本节点

- Python 自定义脚本节点

第15-16周: 数据源扩展 + 模板丰富
- SQL查询, 图片导入, Excel/Parquet 格式
- "视觉缺陷检测" + "设备寿命预测" 模板
