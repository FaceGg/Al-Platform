# 点焊标注实时进度、任务删除与规则编辑设计

## 目标

在现有点焊数据标注流程上做最小扩展：运行中实时刷新任务进度和样本队列；任务列表支持删除终态任务；自动、手动任务详情均可修改规则；自动任务保存规则后重新计算全部自动标签，手动任务仅保存规则作为人工参考。

## 现有问题

- 详情页仅每 1.5 秒刷新运行列表，未同步刷新样本队列，界面进度和队列可能滞后。
- 后端每 100 条提交一次进度，小数据集会从 0 直接跳到 100%。
- 后端已有终态运行删除 API，前端任务列表没有删除入口。
- 配置页规则可编辑，详情页仍为静态规则文本，已有任务无法调整规则。

## 方案

### 实时进度

详情页对 `queued`、`validating`、`running` 状态每 1 秒刷新运行详情和样本队列。刷新后保留当前选中样本；任务进入 `completed`、`failed` 或 `cancelled` 后停止轮询。后端创建样本和规则重算时按最多 10 条一批提交进度，使中小数据集也能看到连续变化。

### 删除任务

任务列表为每行增加删除操作。用户确认后调用现有删除 API，成功后移除任务并刷新列表。后端继续限制只有 `completed`、`failed`、`cancelled` 可删除；活动任务返回 `QUALITY_RUN_ACTIVE`。

### 规则编辑

新增 `PUT /api/projects/{project_id}/spot-weld/runs/{run_id}/rules`，请求体包含完整 `rule_config`。

- 自动任务：校验并保存规则，将状态和标注进度重置为运行中/0；基于现有样本特征重新计算阈值、自动标签和规则命中；不覆盖人工 `current_label`；完成后恢复 `completed`。
- 手动任务：校验并保存规则，不计算自动标签，不修改样本标签和任务状态。
- 两种模式均更新当前任务的规则集记录，序列化结果返回最新规则。

### 页面

详情页使用现有规则字段配置渲染可编辑输入：自动任务标题为“自动标注规则”，手动任务标题为“标注规则”。保存期间禁用按钮；自动任务提示会重新计算全部自动标签，手动任务提示仅作为人工参考。

## 错误处理

- 非法规则：`QUALITY_RULE_CONFIG_INVALID`。
- 活动任务重复保存规则：`QUALITY_RUN_ACTIVE`。
- 不允许重算的运行状态：`QUALITY_RUN_NOT_RECALCULABLE`。
- 删除活动任务：沿用 `QUALITY_RUN_ACTIVE`。

## 验收

1. 运行详情每秒获取新进度，并同步新增样本。
2. 终态任务可在列表删除，活动任务删除显示明确错误。
3. 自动任务保存规则后进度从 0 重新增长，自动标签变化，人工标签保持不变。
4. 手动任务显示“标注规则”，保存后标签不变。
5. 后端相关测试、前端页面测试、生产构建通过。
