# 智擎平台名称变更设计

## 目标

将平台所有面向用户的品牌名称统一改为“智擎”。覆盖登录页、应用侧栏、仪表盘副标题、浏览器标题及中英文界面中的平台品牌名称。

## 范围

- 修改前端生产界面中的品牌展示文案。
- 更新直接断言旧品牌名称的前端测试。
- 保留 `ml-platform`、API 路径、Celery 任务名、存储桶、模型类型、代码符号及仓库目录等技术标识。
- 不修改历史开发记录中的既有事实，不触碰用户当前对 `platform-preview.html` 的未提交修改。

## 实施方式

精准替换现有用户可见的品牌字面量，不新增全局品牌常量。该方式与当前代码结构一致，改动范围最小，也避免将一次文案调整扩展为无必要的配置重构。

## 验证

1. 先增加或收紧品牌文案测试，并确认测试因旧名称仍存在而失败。
2. 修改生产文案后运行相关前端测试。
3. 运行前端全量 Vitest 和生产构建。
4. 搜索生产前端，确认旧品牌文案已清除且技术标识未被替换。
