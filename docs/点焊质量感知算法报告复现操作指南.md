# 点焊质量感知算法报告复现操作指南

## 1. 目的与边界

本指南使用智擎平台复现《点焊质量感知算法报告》的完整业务流程：数据准备、73 维特征工程、10 组 AutoML 候选选型、特征重要性加权聚类、规则弱监督标注、4 模型训练对比和四级缺陷预警。

报告引用的原始数据来自历史 PostgreSQL 表，当前平台未持有该私有数据。因此分为两种复现方式：

| 方式 | 用途 | 可以验证的内容 | 不应作出的结论 |
| --- | --- | --- | --- |
| 报告结构模拟数据 | 平台功能、流程、输出结构和演示验收 | 1875 样本、73 特征、10 候选、标注快照、训练、导出和 8 Sheet 报告 | 不代表原始报告中的 AUC、F1、K 值、缺陷数量或特征重要性数值 |
| 原始结构 CSV/XLS/XLSX | 与报告数据口径进行实际比对 | 相同数据下的候选结果、聚类、标签、模型和预警结果 | 不能用模拟数据替代真实数值结论 |

建议先完成“报告结构模拟数据”全流程，确认环境和平台能力正常；拿到原始结构数据后，用同一流程重跑并比较可验证数值。

## 2. 前置条件

1. 使用有项目访问权限的账号登录智擎，并创建或选择一个专用项目，例如“点焊质量报告复现”。
2. `owner` 或 `editor` 可上传报告、启动质量运行、创建快照和训练；`operator` 可人工标注但不能创建快照或训练；`viewer` 仅可查看。
3. 前端和后端必须处于同一版本。启动后先确认后端健康接口可访问，再打开前端地址。当前本地联调默认后端为 `http://127.0.0.1:8000`；前端端口以实际启动命令为准。
4. 本指南不要求填写服务器文件路径。数据文件上传后由平台生成项目内数据集制品并保留哈希、Schema 和血缘。

## 3. 报告与平台阶段映射

| 报告章节 | 平台入口 | 主要验收结果 |
| --- | --- | --- |
| 2. 数据准备与特征工程 | 数据管理、AutoML 的“点焊质量感知”、数据标注 | 4 路波形解码、25 个表格特征、48 个波形特征、共 73 维 |
| 3. AutoML 算法选型 | AutoML -> “点焊质量感知” | 10 组候选的 AUC、F1、耗时和最优候选 |
| 4. 缺陷聚类 | AutoML 质量运行结果 | 特征重要性权重、K=2 至 K=8 轮廓系数、最优 K、PCA 坐标 |
| 5. 缺陷标注 | 数据标注 | 样本队列、四通道波形、规则命中、人工标注、审核、自动标签快照 |

| 7. 缺陷预警 | 数据标注样本详情、训练结果和报告 | 缺陷概率及 `none`、`notice`、`warning`、`critical` 四级预警 |

## 4. 准备输入数据

### 4.1 最小数据契约

原始报告有 107 列，但平台执行报告复现只要求以下 18 个源字段；其余列可保留，不参与本流程计算。

| 类型 | 必填字段 |
| --- | --- |
| 14 个表格字段 | `wld1c`、`wld2c`、`tipv1`、`tipv2`、`wres`、`energy`、`wld_spatter_strength`、`wld1_spatter_strength`、`wld2_spatter_strength`、`spatterpos_wld`、`spatterpos_pre`、`spotdiameter`、`spotposition`、`spattercode` |
| 4 个波形字段 | `cvei`（电流）、`cvev`（电压）、`cver`（电阻）、`cvep`（功率） |

平台自动生成 11 个衍生表格特征：`current_ratio`、`voltage_ratio`、`power_wld1`、`power_wld2`、`power_ratio`、`energy_per_current`、`spatter_total`、`spatter_asym`、`diameter_norm`、`energy_dev`、`spatter_seg`。每个波形通道再提取 12 个统计量，最终固定为 73 维。

### 4.2 波形编码检查

每个 `cvei`、`cvev`、`cver`、`cvep` 单元格必须是 Base64 字符串，解码后满足：

1. 二进制长度为 1740 字节。
2. 使用大端序有符号 16 位整数（`>i2`）解析。
3. 每个通道得到 870 个采样点。
4. 表格数值不能为空、不能为非数值或无穷值；`wld1c`、`wld2c`、`tipv1`、`tipv2` 不能为 0，因为特征计算包含除法。

字段名必须与上表一致。当前页面不提供别名映射编辑器；若源表头不同，请在上传前整理为这些字段名。

## 5. 路线 A：使用报告结构模拟数据完成全流程

这是首次验收的推荐路线，不需要原始数据。

1. 打开左侧导航“数据标注”，在页面顶部选择目标项目。
2. 点击“模拟数据”，在下拉菜单中选择“报告复现（1875 条）”。平台会生成报告结构 CSV、创建数据制品并启动质量运行。
3. 在“质量运行”下拉框中选择新运行。状态会经历 `queued`、`validating`、`running`，直到 `completed`；可点击刷新图标重新读取状态。
4. 等待运行完成后，确认样本队列显示 1875 条数据，并可在任意样本中查看“自动标签”、规则命中、四通道波形、缺陷概率和预警等级。

本路线的稳定验收基线是 1875 个样本、73 个特征和 10 组候选。当前模拟数据的自动主标签分布为：`normal` 376、`weak_splatter` 469、`strong_splatter` 469、`spot_too_small` 468、`current_jump` 93。该分布用于验证当前模拟器和 5 折训练的可用性，不等同于原报告的历史标签分布。

## 6. 路线 B：用真实 CSV/XLS/XLSX 重跑报告

### 6.1 从数据管理进入（推荐）

1. 打开“数据管理”，选择目标项目并上传 CSV、XLS 或 XLSX。
2. 上传完成后，在该数据行的操作列点击标签图标，鼠标提示为“质量感知 <文件名>”。
3. 页面会跳转到“数据标注”，并带入项目和数据集制品。
4. 点击“运行已选数据”，平台先校验字段和波形，再创建质量运行。

### 6.2 从数据标注直接上传

1. 打开“数据标注”，选择目标项目。
2. 点击“上传报告”，选择 CSV、XLS 或 XLSX。
3. 上传成功后平台自动校验并创建质量运行。

任一方式均可。不要对同一文件同时使用两种方式启动运行，以免产生重复质量运行。

## 7. 执行 AutoML、特征工程和聚类

使用 AutoML 页面可以显式复现报告的输入数据和算法集合选择。

1. 打开“AutoML”，切换到“点焊质量感知”。
2. 选择“项目”和“报告数据”。只显示项目内 CSV、XLS、XLSX 数据集。
3. 在“报告候选算法”中保留空值即可使用全部 10 项；如需显式记录选择，请全部选中：
   `LGB_v1`、`LGB_v2`、`XGB_v1`、`XGB_v2`、`CAT_v1`、`CAT_v2`、`GBDT_v1`、`RF_v1`、`ET_v1`、`HGB_v1`。
4. 点击“运行质量感知”。
5. 等待状态变为 `completed`，在结果区检查：样本数、特征版本 `report_v1`、候选结果表、K 搜索结果、最优聚类 K 和 PCA 尺寸。
6. 点击“打开数据标注”，进入同一质量运行的标注和训练阶段。

平台在该步骤自动完成以下报告逻辑：

1. 按大端序解码四路 870 点波形。
2. 生成 25 个表格特征和 48 个波形统计特征并标准化。
3. 用 3 折分层交叉验证对选中的 10 组候选进行 AUC/F1 比较。
4. 使用最优候选的特征重要性进行加权 KMeans，在 K=2 至 K=8 中按轮廓系数选择最优 K，并生成 PCA 二维坐标。
5. 用聚类结果和 `report_v2` 工艺规则生成自动标签与四级预警。

候选模型的历史排名、AUC 和 F1 会随输入数据、依赖版本和标签分布变化。真实数据复现时，应记录本次结果并与报告历史数值比较，不应预先把 `LGB_v2` 或任一固定分数作为通过条件。

## 8. 执行弱监督标注与人工审核

1. 在“数据标注”选择已完成的质量运行。
2. 左侧“样本队列”可上下滚动；点击样本查看四通道波形、工艺参数、自动标签、聚类、规则命中、缺陷概率和预警等级。
3. 若需要人工确认，选择“人工标签”，填写备注后点击“提交复核”。
4. 由 `owner` 或 `editor` 填写审核意见，再点击“通过审核”或“退回”。

报告复现优先使用规则自动标签：不必逐条人工审核 1875 个模拟样本。真实生产数据则应按工艺专家规则抽检、复核和回流标签，避免将弱监督标签直接视为真实缺陷事实。

新建质量运行使用不可变规则集 `report_v2`。`energy_dev` 是当前质量运行内按能量均值和标准差计算的标准化偏差，因此 `|energy_dev| > 2.5` 等价于能量偏离均值超过 `2.5σ`；两个 P95 阈值也按当前运行的全部有效样本计算。规则按下表顺序确定主标签，但会同时保留每一条命中证据：

| 缺陷类型 | 判定规则 | 说明 |
| --- | --- | --- |
| 强飞溅缺陷 | `wld_spatter_strength >= 3` | 飞溅强度达到 3 级及以上 |
| 弱飞溅缺陷 | `wld_spatter_strength = 2` | 飞溅强度为 2 级 |
| 焊点过小/虚焊 | `0 < spotdiameter < 2 mm` | 焊点直径异常小；`0` 视为未测量 |
| 焊点过大/烧穿 | `spotdiameter > 80 mm` | 焊点直径异常大 |
| 能量异常 | `|energy_dev| > 2.5σ` | 能量偏离均值超过 2.5 个标准差 |
| 电流波形异常 | `current_max_diff > P95` | 电流最大跳变超过当前运行的 95 分位 |
| 功率波动异常 | `power_std > P95` | 功率标准差超过当前运行的 95 分位 |
| 飞溅倾向簇 | `cluster = 1` 且 `wld_spatter_strength >= 2` | 固定使用聚类 ID 1 与飞溅倾向联合判断 |
| 正常 | 以上规则均不满足 | 无异常 |

历史 `report_v1` 运行保留其原始规则版本和结果，不会因本次规则升级被重写。数据标注页会以中文显示自动标签、全部规则命中和判定说明；人工修正也可选择上述全部标签类型。

## 9. 创建训练快照并训练 4 个模型

仅 `owner` 或 `editor` 可执行本节。

1. 确认质量运行状态是 `completed`。
2. 在“审核标签训练”中填写快照名称，例如 `report-auto-labels-20260731`。
3. 将“快照标签来源”选择为“报告复现自动标签”。若要训练人工确认后的数据，则选择“已人工审核”。
4. 点击“创建训练快照”。快照冻结后不可随页面当前状态改变，是训练和模型血缘的标签事实来源。
5. 在“训练标签快照”中选择刚创建的快照，点击“训练快照”。
6. 等待出现“质量模型与报告已生成”，随后可下载质量报告或打开模型库。

该训练比较以下 4 个模型：`AutoML(LGB_v2)`、`MLP_128-64-32`、`MLP_256-128-64`、`MLP_仅表格`。平台按 5 折分层交叉验证生成多分类评估，并把模型、特征 Schema、标签快照 ID、标签来源和规则版本写入既有模型库血缘。

若真实数据提示 `QUALITY_LABELS_INSUFFICIENT_FOR_5_FOLD`，说明某个训练主标签少于 5 条。应补充可审核样本、确认规则或先完成模拟数据验收；不要通过降低折数或静默删除少数类来伪造可训练结果。

4. 缺陷标签
5. 聚类画像
6. 特征重要性
7. 推理结果
8. 多分类评估

建议依次核对标签来源、训练样本数、候选模型结果、聚类统计、特征重要性、每个样本的缺陷概率/预警等级和多分类评估。

### 10.2 标注数据导出

在质量运行已选中时，点击页面顶部“导出标注”。

| 格式 | 内容 |
| --- | --- |
| CSV | 当前“标注样本”数据，包括自动标签、当前标签、审核状态、预警、概率、聚类、规则命中和当前修订 ID |

## 11. 核验报告的预警阶段

质量运行和快照训练会为每个样本保存缺陷概率，并映射为四级预警：

| 平台等级 | 概率范围 | 对应操作建议 |
| --- | --- | --- |
| `critical` | P(defect) >= 0.8 | 立即停线检查 |
| `warning` | 0.6 <= P(defect) < 0.8 | 加密抽检频率 |
| `notice` | 0.3 <= P(defect) < 0.6 | 关注趋势变化 |
| `none` | P(defect) < 0.3 | 正常生产 |

可在样本详情、标注 CSV/XLSX、质量报告“推理结果”页和模型库中追溯该结果。平台当前提供质量感知与预警结果；产线 MES 停线、抽检或通知动作仍应由企业现场流程接入后执行。

## 12. 可选：在工作流中单独复现特征工程

若需要把报告的“2. 数据准备与特征工程”放入可编排工作流：

1. 打开“工作流”，创建一个数据处理工作流。
2. 在处理类算子中添加 `spot_weld_feature_engineering`。
3. 将报告数据表连接到该算子的 `data` 输入端口。
4. 执行后读取 `features`、`schema`、`statistics` 三个输出；其中 `features` 是固定 73 维特征表，`schema` 是字段顺序，`statistics` 含波形点数和特征版本。

该算子复用质量运行相同的波形解码和特征函数，不能与质量运行并行定义另一套特征公式。

## 14. 常见问题

| 现象或错误码 | 处理方式 |
| --- | --- |
| `QUALITY_FIELD_MAPPING_INVALID` | 检查 18 个必填字段名是否存在、是否重复映射；当前页面要求使用标准字段名。 |
| `QUALITY_WAVEFORM_INVALID_BASE64` | 检查对应波形字段是否为空、截断或包含非 Base64 字符。 |
| `QUALITY_WAVEFORM_LENGTH_INVALID` | 检查 Base64 解码后是否为 1740 字节、能否按 `>i2` 得到 870 点。 |
| `QUALITY_FEATURE_NONFINITE` | 检查必填数值列是否为空、非数值、无穷或除数为 0。 |
| `QUALITY_AUTOML_DEPENDENCY_UNAVAILABLE` | 当前后端缺少某个候选模型依赖；检查部署环境依赖后再运行，不要静默删掉候选记录。 |
| `QUALITY_LABELS_INSUFFICIENT_FOR_5_FOLD` | 某个训练标签少于 5 条；补充审核样本或使用 1875 条报告模拟数据验证流程。 |
| 质量运行长期未完成 | 点击刷新质量运行；确认前端代理指向带质量路由的后端，并检查后端任务日志。 |
