# 智擎平台操作指南

本指南覆盖当前平台的主操作路线：项目管理、数据管理、点焊数据标注、自动建模、工作流、模型与运维查看。

## 1. 登录与权限

1. 在浏览器打开部署地址，例如 `http://<服务器地址>/`。
2. 使用部署负责人交接的账号登录；首次登录后立即修改密码。
3. 管理员可在“用户管理”创建平台账号；项目内再按实际职责分配 owner、editor、operator、viewer 权限。

常用权限边界：

| 角色 | 主要能力 |
|---|---|
| owner | 管理项目成员、数据、工作流、标注规则、训练、模型和导出。 |
| editor | 编辑项目数据、工作流、标注和训练配置。 |
| operator | 执行任务、查看数据、进行人工标注和提交复核。 |
| viewer | 只读查看项目资源和结果。 |

## 2. 推荐主流程

```text
项目管理 -> 数据管理上传数据 -> 点焊数据标注 -> 保存带 label 的数据集
-> 自动建模/点焊质量感知 -> 查看任务、报告、模型和制品
```

没有 `label` 的原始点焊数据不能直接作为监督式普通 AutoML 的训练目标。先自动或手工标注，再“保存到数据管理”生成追加 `label` 列的新数据集。

## 3. 创建项目并上传数据

### 3.1 创建项目

1. 进入左侧“项目管理”。
2. 点击“新建项目”。
3. 输入项目名称和描述后保存。
4. 在项目详情确认成员和角色，之后所有数据、任务、工作流和模型均按项目隔离。

### 3.2 上传数据

1. 进入“数据管理”。
2. 在项目下拉框选择刚创建的项目。
3. 上传 CSV、XLS 或 XLSX 文件。
4. 上传完成后查看 Schema、行数、预览和数据集制品信息。

数据集制品是平台内的受控数据文件。后续工作流和训练页面从下拉菜单选择它，不需要填写服务器路径或 Artifact ID。

## 4. 点焊数据标注

### 4.1 点焊报告字段

点焊质量感知与自动标注需要原始报告中存在以下 18 个源字段。列名前后的空格和 UTF-8 BOM 会自动兼容；缺列会被拒绝并提示具体字段。

```text
wld1c, wld2c, tipv1, tipv2, wres, energy,
wld_spatter_strength, wld1_spatter_strength, wld2_spatter_strength,
spatterpos_wld, spatterpos_pre, spotdiameter, spotposition, spattercode,
cvei, cvev, cver, cvep
```

其中 `cvei`、`cvev`、`cver`、`cvep` 分别保存电流、电压、电阻、功率波形的原始数据。除上述字段外，标注详情会显示上传文件中的全部实际列。

### 4.2 创建标注任务

有两种入口：

1. 在“数据管理”中选择点焊报告所在行，点击“自动标注”图标。
2. 进入左侧“数据标注”，选择“点焊数据标注”，再新建自动或手动标注任务。

随后选择项目和数据集，或直接上传 CSV/XLS/XLSX。其他四类标注入口当前显示为“暂未开放”。

### 4.3 自动标注

1. 选择“自动标注”。
2. 检查并按现场规则修改阈值，点击“开始自动标注”。
3. 在任务列表查看模式、状态及 `已标注数量/全部数量 百分比`。
4. 打开任务详情，样本队列会同步显示相同进度；任务完成后显示 `completed` 和 `100%`。

内置规则如下，规则参数可在创建页或详情页修改。自动模式保存规则后会重新计算自动标签，不会覆盖人工 `label`。

| 缺陷类型 | 默认判定规则 |
|---|---|
| 强飞溅缺陷 | `wld_spatter_strength >= 3` |
| 弱飞溅缺陷 | `wld_spatter_strength = 2` |
| 焊点过小/虚焊 | `0 < spotdiameter < 2 mm` |
| 焊点过大/烧穿 | `spotdiameter > 80 mm` |
| 能量异常 | `|energy_dev| > 2.5σ` |
| 电流波形异常 | `current_max_diff > P95` |
| 功率波动异常 | `power_std > P95` |
| 飞溅倾向簇 | `cluster = 1` 且飞溅等级 `>= 2` |
| 正常 | 以上规则均不满足 |

### 4.4 手工标注与复核

1. 创建时选择“手动标注”，进入任务详情后直接对样本操作。
2. 点击左侧样本队列中的任意样本。
3. 上半部分显示可编辑的“标注规则”；手动模式中的规则仅作为判断参考。
4. 下半部分“当前样本数据”显示原始数据中的全部真实列。与规则命中的关键值为绿色，不命中的相关值为红色；`label` 单独显示当前人工标签。
5. 选择“正常”或任一缺陷标签。标签会立即保存；切换样本时也会自动保存当前人工结果。
6. 完成一批样本后，点击页面顶部“提交复核”。

支持的标签：正常、强飞溅缺陷、弱飞溅缺陷、焊点过小/虚焊、焊点过大/烧穿、能量异常、电流波形异常、功率波动异常、飞溅倾向簇。

### 4.5 导出和回写数据管理

在已完成的标注任务详情页：

- “导出标注”可导出 CSV 或 XLSX，包含标注样本和标签信息。
- “保存到数据管理”会创建一份新的项目数据集制品：保留原始列，并在末尾追加 `label` 列。
- 不会修改原始上传文件，因此可保留原始数据与标注数据的血缘关系。

任务列表只允许删除 `completed`、`failed` 或 `cancelled` 的终态任务；运行中的任务不可删除。

## 5. 自动建模

进入左侧“自动建模”后，顶部会按当前项目汇总“普通建模”和“点焊建模”任务，显示状态、建模进度、错误详情和删除操作。

### 5.1 普通 AutoML

适用于已经存在目标列的数据集，例如通过标注回写生成的 `label` 数据集。

1. 选择项目、实验和数据集。
2. 选择目标列 `label`。
3. 选择数值输入列；目标列不能同时作为输入列。
4. 选择任务类型和算法集合。
5. 选择是否启用交叉验证；启用后可选 3、4 或 5 折。
6. 点击“运行”。

结果页会展示最佳模型、模型对比、分数和每个候选算法的真实训练耗时。任务完成后可在训练管理、模型库和数据制品中继续查看相关资源。

### 5.2 点焊质量感知

适用于原始点焊报告。它会基于固定的 18 个源字段构建点焊特征，因此这些必需字段不能从输入列中移除，也不能作为目标列。

1. 切换到“点焊质量感知”标签页。
2. 选择项目和符合 18 列契约的报告数据。
3. 可选监督目标列；无 `label` 时使用自动标注规则进行质量运行。
4. 选择报告候选算法和是否启用 3、4、5 折交叉验证。
5. 点击“运行质量感知”。
6. 完成后在“主要报告”查看指标、候选训练耗时和五张图，点击“下载完整报告”导出 XLSX。

完整报告包含 8 个工作表：总览、AutoML选型、深度学习对比、缺陷标签、聚类画像、特征重要性、推理结果、多分类评估；页面主要报告显示 AutoML 模型对比、聚类 PCA、特征重要性 Top20、缺陷预警分布、正常与缺陷波形对比五张图。

## 6. 工作流

1. 从“项目管理”进入项目详情，创建工作流或使用模板。
2. 在工作区拖入算子、连接端口并保存。
3. 数据导入类算子使用“数据集制品”下拉菜单选择匹配格式的项目数据，不填写 Artifact ID。
4. 点击“运行”，在节点状态、运行记录和日志中查看结果。
5. 使用“写入 CSV”或“CSV/Excel 导出”时，输出会先保存为项目的数据集制品；选中已完成的导出节点后，再点击下载按钮把同一份持久化制品下载到本地。

点焊特征工程算子会保留原始 `cvei`、`cvev`、`cver`、`cvep` 字段，便于后续导出和追溯。

## 7. 结果、模型与监控

- “训练管理”：查看普通训练任务、状态、参数、指标和日志。
- “模型库”：查看训练产生的模型、版本、制品和部署状态。
- “监控”：查看平台资源、任务和模型相关状态。
- “数据管理”：查看原始数据、回写的带 `label` 数据集及工作流导出制品。

遇到任务失败时，先记录任务 ID、错误码、失败时间和页面操作，再由部署管理员查看 `backend`、`worker`、`scheduler` 容器日志。

## 8. 常见问题

| 提示或现象 | 含义与处理 |
|---|---|
| `QUALITY_FIELD_MAPPING_INVALID` | 点焊报告字段无法映射。检查 18 个必需列、BOM、列名空格和上传格式。 |
| `QUALITY_INPUT_COLUMNS_INVALID` | 点焊质量感知的数据集或输入列不符合固定源字段契约。选择兼容报告，等待预览完成后再运行。 |
| `TRAINING_DISPATCH_FAILED` | 训练任务未进入队列。联系部署管理员检查 Worker、Redis、`/api/ready` 和容器日志。 |
| 自动标注长期为 0% | 先刷新任务详情；若服务端仍无进度，检查 Worker 日志和点焊报告字段。 |
| 工作流导出后本地没有文件 | 先在节点运行成功后选中导出节点，再点击下载按钮；输出同时可在数据管理中找到。 |
| 普通 AutoML 没有可选目标列 | 数据集尚未有 `label` 或其他目标列。先完成标注并保存到数据管理。 |

## 9. 使用原则

- 原始数据、自动标签、人工标签和回写数据集是不同事实，保留原始数据并通过制品血缘追溯。
- 规则修改应由项目 owner/editor 结合工艺规范完成，并记录变更原因。
- 模型指标仅代表所选数据、标签与验证配置；上线前应结合独立验证集、工艺审核和现场试运行。
- 不要在工作流中的 `execute_python`、表达式或自定义算子中执行不可信代码。
