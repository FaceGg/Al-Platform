## 执行顺序

1. 先运行后端隔离模块回归和前端 Vitest，定位确定性回归。
2. 执行前端生产构建和 Playwright 焊接质量主流程。
3. 有 Docker 服务时执行 PostgreSQL、Redis、MinIO、Celery 生产集成；没有服务时显式记录跳过，不视为通过。
4. 第 6-8 周功能代码进入工作区后，按本清单新增独立测试模块并写入 `week_manifest.py` 和 `weekAcceptance.test.ts`，再执行完整第 1-8 周验收。

## 通过标准

- 每条自动化用例均有唯一归属周次、稳定测试数据和明确断言。
- API、任务、数据库和浏览器测试均通过后，周次才可标记为已完成。
- 被跳过的生产集成、未实现功能或未覆盖的用例必须单独列为风险，不能计入通过数量。
